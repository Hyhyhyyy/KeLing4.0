# Kotlin I1：带可核对资料的 AI 问答

日期：2026-10-29 至 2026-10-30。版本：`3.2.2-preview` / `versionCode=12`。本记录只说明 Android 实现；共享字段依据 [AI_CONTEXT_CONTRACT.md](AI_CONTEXT_CONTRACT.md)，服务端和 Web 验证由主线另行记录。后续用户追加了免登录内存试用及用户自行配置模型 Key，并取消定时迭代；本轮按有限交付完成，没有创建或恢复自动任务。

## 问题与本轮实现

此前 Android 只能从一个空问题进入助手，用户需要自己复制课程或笔记，而且历史来源界面只出现在成功回答中。本轮让课程、任务和已保存笔记各自提供入口：先取真实资料预览，再编辑问题，最后由用户点击发送。入口只携带资源类型、ID 和通用的初始问题，不传完整笔记，也不自动创建云会话或调用模型。

- `MainActivity.kt` 在当前账户和登录会话下暂存入口；消耗后立即清除，返回按钮回到相应课程、任务或笔记页。
- `CloudWorkspaceScreen.kt` 为三类资料增加入口。笔记编辑窗口提示先保存，编辑时不能点击底层 AI 入口；保存失败保留编辑内容，成功后才关闭。修正旧保存次数在页面重建时误关闭编辑窗口的问题。
- `AssistantApi.kt` 增加 `POST /ai/context-preview`、发送请求中的可选 `context`，以及来源的可选版本时间和截断标识。普通聊天不编码 `context: null`，兼容原接口；旧来源默认没有版本时间。
- `AssistantViewModel.kt` 保存草稿、预览范围、加载/失败状态和服务器指纹。指纹是标识资料版本的校验值，不是权限凭据；只作为请求字段传回，不在界面展示。每次切换主题使旧请求代次失效，并取消仍在等待的本地请求。
- `StellarAssistantScreen.kt` 提供真实预览、完整摘录与版本查看、截断提醒、刷新和移除。模型未配置也能预览和编辑；发送禁用并说明原因。来源来自本轮提交时的快照，失败或取消也能展开核对；旧记录显示“旧会话未记录版本”。

## 一次请求怎样流转

1. 选择课程/任务/已保存笔记 → 新的本地对话状态与可编辑问题。
2. 客户端向共享 API 提交 `{kind,id}`，读取服务端按账号过滤后的标题、片段、限制提示、版本及指纹。此时没有模型调用，也没有创建云会话。
3. 用户核对并点击发送 → 创建云会话（如尚未创建），发送 `{message,clientRequestId,context:{kind,id,fingerprint}}`。指定资料时关闭新会话的全局检索选项；已有会话历史仍可能参与回答。
4. 服务端重新检查资源归属与版本。若返回 409，客户端使原预览失效，保留问题并要求刷新；刷新不会自动重发，用户再次点击后使用新的请求编号。404 同样保留问题，可移除或重新选择资料。
5. 成功提交后清空已提交的同一问题，读取共享会话。若用户在等待中写了其他问题，则保留新文字。每条历史消息可以查看其来源快照。

临时选择只存在于当前登录界面的内存。切换历史、新对话或离开助手会清除来源；带来源问题离开时一并清除并在返回后说明。普通配置变化可保留 ViewModel；进程重建不假定恢复来源，界面明确提示当前未附带指定资料。账户和令牌分别绑定状态，旧请求不能向新选择回填结果。

## 视觉适配

新场景使用同一套共享 PNG，并以现有 144 dp 短幅场景卡适配手机。`scene_planning` 对应智能编排，`scene_profile` 对应个人页，`scene_settings` 对应设置页；`scene_lab` 只用于 AI，`scene_archive` 用于笔记，`scene_garden` 用于课程，`scene_focus` 用于任务，`station_full` 用于首页。首页移除对 AI 和任务大场景的重复使用，改用文字操作卡和导师小形象。文字及操作控件保留在独立表面，不写进图片。

登录和注册使用各自独立的 `scene_login`、`scene_register`，按原图 3:1 比例显示横幅，并为表单增加键盘避让。设置页发现通知、学习提醒、签到提醒、音效及震动 5 个开关此前仅改变页面内状态，未控制实际功能；本轮移除假生效状态，全部禁用并分别明确“尚未接入”。没有新增通知权限，也没有用本地偏好开关冒充通知或音效实现。

## 免登录试用与自己的模型 Key

登录页的“免登录试用”进入独立 `TrialScreen`，不触发登录成功，也不创建账号。`TrialSession` 是由当前页面 `remember` 持有的普通内存对象，没有账号仓库、DataStore、Room、文件或偏好存储依赖。试用提供内置课程与知识点、任务添加/删除/完成、暂停/继续的专注计时、笔记新建/编辑/删除、资料预览和模块导航。完成任务及记录的分钟仅改变当前内存，没有账户积分或云同步。

试用中的问题和资料只有在明确发送时才交给模型。内置固定示例标明“非实际 AI”，不会根据用户问题伪装生成。公共模型通过 `GET /trial/config` 获取可用状态，未配置时仍可完整操作其他模块；`POST /trial/ai` 无账号鉴权、无云端会话。真实回答不会自动改动任务和笔记，用户可以明确保存到本次内存笔记，或先编辑任务标题、说明和时间，再确认创建。取消保留当前问题；退出取消请求并清空可访问状态，晚到响应不能重新写回。

常规 AI、设置、免登录试用均有显眼的“自己的 API Key / 实时模型”入口，复用 `ModelAccessPanel` 与 `ModelAccessSession`。API Key 是用户从模型商取得的访问凭据，只放在此面板的内存状态，关闭即清空；不写账号、偏好、日志或云会话。界面采用密码输入、关闭自动纠正，并对窗口启用 Android 安全标记；并未宣称可对 JVM 字符串做物理内存擦除。

Key 的候选识别在本机执行：`sk-ant-`、`sk-proj-`/`sk-svcacct-`、`AIza` 只给出相应候选；普通 `sk-` 和 JWT 类格式明确无法确定。不会自动向厂商验证。用户从服务端目录选择一家厂商和所需官方地域，点击“验证并获取模型”后，才调用 `POST /model-access/discover`。模型下拉来自本次接口返回，显示获取时间和能力信息；仅向量模型不能直接聊天，能力未知或目录不受支持时，可手填模型 ID 并实际发送验证。地址由服务端白名单约束。

`POST /model-access/complete` 只提交所选厂商、Key、模型、问题及预览资料；不带账号 Authorization，不创建共享会话。界面说明可能产生该模型账户用量，以及模型商保留策略并不由课灵保证。临时问答请求上限为 95 秒，给服务端 85 秒处理上限留出网络余量；取消本地等待不保证厂商停止已收到的调用。常规面板提供用户主动复制回答；试用面板提供主动保存内存笔记或编辑后创建内存任务，随后关闭并清除 Key。

临时数据不跨设备、不作为资料备份，也不自动恢复。页面销毁（包括配置变化导致重建）、退出或进程关闭会清空本次试用和 Key 面板；已明确复制到系统剪贴板的常规回答由系统管理，不属于本应用内存清理范围。

## 已知边界与未验证项

MockEngine 模拟网络响应，用来验证客户端请求及状态变化，不能替代公网模型、服务端权限检查或跨端真机验收。没有在本轮宣称真实 AI、AgentArts、HarmonyOS 原生支持或 Compose 性能提升已验收。通知、提醒、音效和震动仍是待实现能力，界面现已禁用并如实标记。

本轮 `adb devices -l` 没有已连接设备，未取得真机键盘、大字体、TalkBack、旋转、返回、场景裁切或系统安全窗口的运行证据。同账户 Web/Android 的真实多端操作与冲突回路、真实模型调用及计费、模型商保留策略也未以真机/真实 Key 验收。模型目录可读取不等于其中每个模型都能调用；协议模拟响应不能作为所有厂商测通的证据。Android 构建仍是 Kotlin APK，不是原生 HarmonyOS 安装包。
