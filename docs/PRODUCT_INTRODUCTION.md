# 课灵产品介绍

Web 与 Kotlin Android 学习应用。当前主题探索候选版为 4.3.1-research-rc2，实现与验证见[本轮记录](validation/topic-research-release-2026-11-28.md)、[主题星球设计](design/TOPIC_PLANETS.md)与[知识星图编辑器](design/KNOWLEDGE_GRAPH_EDITOR.md)。

课灵把学习设计成一次知识星球探索。探索者自己决定想学什么，星芽陪伴展开路线；读一段、试一题、看解析，把发现记下来，再安排下一次学习。游戏情境承载学习行动，进度来自实际操作记录。

## 从自己的问题开始

新工作区从空白开始。看完启航故事后，输入想了解的主题、已有基础与目标。主题可以是学科，也可以是网络用语、多义词或抽象概念。系统先取得实际检索资料，再区分不同语境、比较解释的依据与边界，生成学习内容、练习和完整知识图谱。资料不足或主题缺少支持时停止生成，请用户补充具体用法。预览确认后，才建立课程和第一项任务。

可选择综合辨析、通识原义或网络文化语境。数学、英语、历史、计算机、经济、政治、语文、物理、化学、生物、地理、艺术保留专属原画；开启定制形象时，系统另行检索角色或主题的外观资料，从实际网页取得可用参考图，将识别特征设计进球体轮廓、地貌和建筑，保留角色本色。没有取得可用参考图片时，只能依据实际检索文字设计，不会冒称已参考图片。用户可以追加构图、配色等要求单独重绘，失败时保留原图。插画表达主题，不作为知识证据。

开场故事的邀请是：**让我们一起一步一步探索这个知识星球的每一方寸文明！**

现有账号课程保留。二叉树仍作为明确选择的规则练习示例，不再自动填入每位新探索者的工作区。任意学科生成不等于每门学科的内容都已经审核。

## 完成一次学习闭环

1. **选择区域。** 根据自己的起点进入知识讲解，阅读例题。
2. **作答并核对。** 可选6、12或18题，支持单选、多选、判断、填空、排序和简答，按资料选择适用类型；6题至少包含3类，12或18题至少包含4类，不为凑齐种类强加没有依据的排序题。选择题通常有4至6个选项；简答先写自己的解释，再对照参考要点自核，不称为AI评分。对某一题不满意，可追加要求只重生这一题，其他题目和图谱保留。
3. **记录发现。** 用自己的话写航行日志，保存到笔记，留下理解与仍有疑惑的部分。
4. **接上下一步。** 把后续行动加入任务，使用专注计时和完成记录推进学习。
5. **重新打开。** 账号数据从服务端读取，游客数据仅在本次会话中保留。练习进度不冒充经过测量的知识掌握度，也不自动发放未经规则认可的奖励。

原二叉树示例保留遍历、栈和队列的操作与反馈回放，和模型生成的阅读、多题型练习路径分别呈现。

遇到想多练的知识点，可点“相似碎片搜索”，重新检索后再做两道同题型练习。新题与原题并存，原答案和已完成区域保留。进入答题阶段后收起参考资料，仍可随时回看学习或“问星芽”；星芽先给思路和提示，默认上下文不包含参考答案和解析。

## 让知识关系看得清

首次生成星球时，就能查看模型依据学习基础和实际资料组织的知识图谱。节点概括义项、概念、应用、争议和边界，分支与层级按内容决定，最多48个节点、96条关系。点选节点可看摘要和对应来源；从属关系与跨分支关联分开表示。确认前即可浏览，确认后保留完整图谱，并为课程建立实际知识节点。

课程星图使用本地嵌入的 AntV X6 绘图引擎与 Dagre 自动排布。它们负责把知识节点和关系排成可操作的图形。课程编辑器支持缩放、拖动、查看全图、编辑知识点和保存布局；生成预览为只读，不会因误拖而改变模型内容。

网页与 Android 使用同一份绘图代码，手机界面保留原生知识点对话框。保存时检查数据版本，发生冲突会提示重新读取，保存失败保留当前调整。这个引擎负责图形编辑，不能判断教材内容是否正确。

## AI 与资料如何配合

学习星球、资料问答、学习计划与复盘已接入妙搭公共模型。资料问答从选定课程、笔记和任务准备上下文，用户先预览再发送；实际回答能保存为笔记并跨端重开，保留问题、模型及资料来源。计划读取所选资料与时间预算，生成后先检查来源、日期和时长，用户确认才创建任务，重复确认不会重复创建。复盘依据已经保存的任务状态给出下一步建议，不自动证明用户已经学会。

主题星球使用实际联网搜索返回的标题、网址与摘要，编号后交给模型；题目、区域和图谱节点引用这些编号。生成后复核题目、课文和图谱中的依据、答案矛盾和单位问题，程序检查审核覆盖、引文原文和可计算的排序。发现问题最多修复一次，仍不合格则停止；审核本身也是模型输出，不能替代教师审阅。没有取得资料时不把模型记忆冒充联网结果。搜索摘要不等于完整网页，多个网址也不必然是独立证据；输出仍需核对，不能承诺任意造词都有可靠答案。

本轮真实调用与失败修复见[主题探索验证](validation/topic-research-release-2026-11-28.md)。此前十二个通用AI成功样本见[2026-11-27记录](validation/native-ai-live-evidence-2026-11-27.md)，它们是历史调用证据，不代替本轮测试，也不构成长期稳定性或教学效果评估。账号资料检索仍使用关键词与来源快照，向量模型未启用；个人Key目录中的厂商没有逐一验收。

模型输出保留“待核对”状态。真实生成的历史和数学内容已观察到术语与事实边界问题，因此结构校验只证明格式可用，不能代替教师审题。原华为工作流位于另一个账号，API 已真实返回计划，但内部模型节点仍须账号持有人核验，具体操作见[账号交接文档](handovers/huawei/README.md)。妙搭模型验证不能替代这项华为内部核验。

## 两端与使用边界

个人空间保留头像、头像框、称号牌与成就家具各十项，奖励对应实际记录，例如创建第一颗星球、记录学习时长。首页小日历与打卡相邻，帮助回看每天的学习轨迹；100小时成就依据累计6000分钟记录解锁，不以展示用数字替代真实进度。

账号课程、任务、笔记和学习记录通过同一服务保存。游客无需登录，可以使用本次工作区，但刷新、退出或进程结束后清空，也不会自动迁入账号。用户导出的文件不由应用自动删除。

Web 可在浏览器或桌面安装入口使用；移动端为 Kotlin Android，不能称为原生 HarmonyOS。已有公开版本使用相同调试签名，便于覆盖安装。实际更新版本、下载摘要与验证范围以发布记录为准。

网页使用 React、TypeScript、Vite，Android 使用 Kotlin、Jetpack Compose，服务端使用 Express、Prisma。当前托管入口是妙搭，沿用原 PostgreSQL 账号数据；本地开发使用隔离的 SQLite。

实体设备兼容、真实课堂效果、学习收益和本届完整参赛合规需要各自的证据。当前没有学生对照研究，不宣称成绩提升比例或市场领先。项目原画和开发使用 AI 辅助，源文件、提示词与验证记录保留供追溯。
