# 课灵产品介绍

Web 与 Kotlin Android 学习应用

版本 4.0.0-preview　更新日期 2026 年 10 月 30 日

课灵把课程资料、动手练习、AI 辅导与日常任务连成一条可追溯的学习流程。学生先看资料、尝试操作，再依据反馈解释自己的思路；AI 提供建议，规则记录证据，用户决定保存与执行。

主视觉由 AI 辅助生成，是产品美术资源，不是运行截图。实现与验证见[本版交付记录](GAMIFIED_UPGRADE_2026-10-30.md)。

## 01 产品定位与使用价值

课灵面向需要管理课程、理解知识并落实计划的学生，解决资料与待办分散、问答缺少依据、练习缺少过程反馈和多端难以接续的问题。

四个主入口分别为远航、星图、基地、我的，组织练习、课程目标、学习装饰与个人记录。原课程、笔记、任务、报告和模型配置继续可达。本版以二叉树为首章，包含三个目标和十八道原创变式。任意导入材料可用于检索、知识点候选和 AI 辅导，尚不能自动生成已审核的可玩关卡。

## 02 完成一次学习闭环

**整理资料 → 选择目标 → 动手操作或解释 → 反馈与回放 → 确认下一步 → 留下证据与复习安排**

1. **开始远航。** 选择课程、目标和可用时间。10、20、25 分钟是任务建议，不冒充实际用时。会话计时扣除明确暂停时间，也不能证明用户始终在学习。
2. **操作与解释。** 路线修复涉及遍历、栈和队列；教星芽要求解释概念。可点选操作，也保留传统输入控件。
3. **具体反馈。** 规则指出首次偏差，允许回看步骤；请求提示影响独立完成证据，AI 回复不能直接更改判定或奖励。
4. **确认与继续。** 确认反馈后进入下一题、暂停或结束。唯一凭据保证重复提交不重复发奖。线下自述另行标记，不能替代题目证据。
5. **复习与基地。** 记录汇入星图，基地可选购和装备独立绘制的装饰。严格徽章受人工审核等条件约束，尚未完成的审核不会伪装为已掌握。
6. **安排任务。** 输入日期、考试期限、时间窗、每日预算与休息安排，系统避开课程及已有任务。先预览可安排项、未分配项和变化，再确认写入；重复确认不重复加任务。

## 03 两端共享与免登录使用

| 能力 | 网页端 | Kotlin Android |
| --- | --- | --- |
| 学习主流程 | 四入口、题目、回放、资料与计划 | 相同数据合同和规则，适配触控布局 |
| 账号数据 | 共享服务保存课程、任务、记录与证据 | 相同账号接续已提交内容 |
| 离线与接管 | 按账号隔离草稿和待提交队列 | 按账号与服务地址隔离本机草稿 |
| 游客 | 页面内存共用，刷新即结束 | 活动内存共用，界面重建或进程结束即清除 |
| 视觉 | 宽屏场景、操作台与面板 | 相同风格资源配合移动卡片与触控尺寸 |

游客可使用当前端已实现功能；再次打开不恢复上一轮数据，也不自动迁入账号。游客 AI 为无状态转发，但模型商可能处理内容并收费。用户导出的文件与剪贴板不由应用自动删除。

同步以已提交数据为准。同一远航只有一个写入设备，另一端需主动接管；冲突保留草稿，不用旧记录覆盖新状态。协议与数据库验证不能代替真实双设备验收。

当前共享 60 张像素资源，包括十款知识星球、远航、星图、基地和三款独立装饰；两端原画逐字节校验一致。操作动画尊重低动效偏好。

## 04 AI 如何参与学习

在 API Key 模块填写凭据，确认厂商和官方地域，再主动获取模型目录。前缀检测只提供候选；相似 Key 无法保证准确识别，不会向多家服务自动试探。

预设 17 家服务：DeepSeek、阿里云百炼、Kimi、智谱、硅基流动、火山方舟、腾讯混元、华为云 MaaS、OpenAI、Anthropic、Google Gemini、OpenRouter、百度千帆、MiniMax、xAI、Mistral、Groq。不支持目录时可填写已开通的模型 ID；目录可见不等于可用额度或权限。

| 场景 | 参与方式 | 用户控制和限制 |
| --- | --- | --- |
| 课程问答 | 预览节点、最新材料、证据、近期反馈及伙伴记忆 | 明确发送，可移除资料，说明截断范围 |
| 材料辅导 | 文字、Markdown、文字 PDF 按版本检索，回答带引用 | 无扫描件 OCR，材料变化后拒绝过期结果 |
| 练习求助 | 先记录提示，再带允许信息进入助手 | 不发送隐藏答案，提示影响独立完成资格 |
| 笔记与计划 | 回答可保存，AI 建议与确定性日程编排分别标注 | 不自动修改数据，预览确认后写入 |
| 伙伴记忆 | 查看、修改和删除自述 | 不作为心理诊断或客观学习结论 |

文字 PDF 限 512 KiB、50 页，解析有时间和内存上限。引用按版本、内容摘要、页码与 UTF-16 位置定位。知识图候选来自材料标题提取，明确标记提取方式。当前有界摘录、关键词检索及既有可选向量路径，不等于全库向量数据库。

**真实模型未实测。** 用户暂无有效 Key；厂商连通性、权限、回答质量、向量效果、计费和 AgentArts 运行均未完成本版真实验收。合成响应测试不能作为真实 AI 效果。

## 05 技术与适用边界

网页采用 React、TypeScript、Vite；移动端保持 Kotlin 与 Jetpack Compose；服务端采用 Express、Prisma。云端预览运行于 Vercel 和 Neon PostgreSQL，本地可使用 SQLite。共享规则与 Kotlin 镜像使用同组样例；账号奖励由服务端事务决定。

项目按 2026—2027 届华为 ICT 创新赛方向准备。华为云 MaaS 是可选入口，AgentArts 保留适配路径；当前部署不是华为云，Kotlin Android 不是原生 HarmonyOS。尚缺附件 3 赛题细则，不能宣称完整赛事合规。

差异化设计将操作证据、可控 AI、反馈回放和像素基地联系起来；尚无学生对照研究，不能声称已经提高成绩或优于所有竞品。多人社交、全学科自动关卡、原生 HarmonyOS、严格内容人审和学习效果研究属于后续范围。

## 06 开始使用与复现

网页：[完整游客试用](https://keling-ict-preview.vercel.app/trial)。源码：[Hyhyhyyy/KeLing4.0](https://github.com/Hyhyhyyy/KeLing4.0)。Android 为 4.0.0-preview、versionCode 16，预览 APK 使用调试签名，最低 Android 8.0，不作为商店正式包。

本地使用 Node.js 22.13 或以上版本，依次执行 npm ci --ignore-scripts、npm run setup:local、npm run dev。Android 使用 JDK 17 和 SDK 34。API、签名和校验命令见 README、[部署说明](DEPLOYMENT.md)及[迁移恢复说明](design/DATA_MIGRATION_AND_RECOVERY.md)。

后端 68 项、新网页 25 项、旧游客 24 项、Android 78 项测试通过；干净安装、构建、60 张资源校验，以及临时 PostgreSQL 分支七组事务验证通过。Android lint 无错误，有 97 条既有警告。发布及 APK 摘要以本版交付记录为准。

新版浏览器视觉、小屏与大字模式、Android 真机、真实模型及学生使用效果仍需独立验收。旧版截图只作为带版本标注的历史材料。未设置周期性迭代任务；正式提交仍需补齐报名签章、赛题核对与新版演示录制。
