# 课灵产品介绍

Web 与 Kotlin Android 学习应用

版本 3.2.4-preview　更新日期 2026 年 10 月 30 日

课灵把课程资料、带来源的 AI 问答、笔记和学习任务放在同一条操作流程中。网页与 Kotlin Android 均提供免登录进入完整应用的游客模式：正式应用当前已实现的功能入口不因未登录而隐藏，课程、任务、笔记、会话和配置在本次使用中跨模块保留。登录账号用于长期保存和跨端同步；游客内容不在下次打开时恢复，也不会自动转存到账号。

## 01 产品定位与使用价值

课灵面向需要把课堂资料变成实际学习行动的学生。课程、笔记和待办常常分散；向 AI 提问时缺少必要材料；得到解释后没有沉淀自己的理解；换到手机后又难以接续电脑上的学习。

产品以具体问题为起点：选择相关资料，看清模型将收到什么，再编辑并发送问题。回答之后，由学生决定保存哪些内容、安排什么任务，并在执行后补充自己的理解。AI 提供解释和建议，保存笔记、创建任务和确认完成仍由学生操作。

游客模式复用正式界面和操作流程，适合不注册就开始使用；账号模式适合长期管理与跨端接续。没有有效模型配置时，课程、知识点、任务、计时、笔记、报告和个人设置仍可操作，AI 会明确提示配置需求，不以固定答案冒充实时模型回答。

## 02 从资料完成一次学习

以学习“二叉树遍历”为例，可以按下面的路径操作：

**整理课程与知识点 → 选择资料并核对预览 → 编辑问题 → 明确发送**

**核对回答及引用 → 保存自己的笔记 → 预览并确认学习计划 → 专注执行 → 查看记录**

1. **整理资料。** 创建课程、编辑知识点或笔记。学习数据在当前模式内被各模块共同使用；游客的资料不会混入已登录账号。
2. **核对发送范围。** 从课程、已保存笔记或任务进入 AI，查看标题、摘录、版本及截断说明。进入入口不会自动调用模型；可刷新或移除资料，问题保留供修改。
3. **选择模型并发送。** 在明显的 API Key 模块填写自己的模型凭据，核对厂商与官方地域，主动获取模型目录或填写模型 ID。点击发送才提交问题、允许的历史与已选择资料。
4. **保存可追溯的理解。** 回答显示引用资料快照和服务实际报告的用量。点击保存后才进入笔记；游客笔记只属于本次空间。会话可以切换、取消生成和删除；网页还支持搜索与导出。
5. **预览学习计划。** 智能编排基于课程资料和目标生成计划，校验日期、每日时长及来源，再由用户确认加入任务。再次确认同一计划不会重复添加；资料变化时应重新规划。
6. **执行与复盘。** 在任务中计时、暂停、继续并确认完成，再查看学习记录和统计。预计时间不应冒充实际用时，统计和手动掌握度不代表 AI 已客观测出学习效果。

资料在预览后发生变化时，系统会拒绝旧版本请求，保留问题，要求刷新后再次确认。停止生成会停止等待或取消当前工作；已送达模型商的请求仍可能继续处理和计费。

## 03 完整游客与账号模式

| 使用方式 | 可使用的应用功能 | 保存与同步 |
| --- | --- | --- |
| 免登录游客 | 使用当前端正式应用已实现的全部模块入口，包括课程、知识图谱、任务、笔记、AI 会话、编排、报告、签到、成就和设置；AI 仍需要有效模型授权。 | 本次使用中跨模块保留，结束后清除；不写入学习数据库，不跨设备同步，不自动迁入登录账号。 |
| 登录账号 | 使用相同的正式模块，按当前端的布局与功能适配操作。 | 通过共享服务长期保存已提交数据，网页与手机使用同一账号可读取共享内容；联网和服务可用性仍是必要条件。 |
| 临时单次 Key 问答 | 保留独立的单次问题入口，可明确选择资料和保存回答；它不是功能较少的游客替代品。 | 不自动创建账号共享会话。游客 Key 可供本次 AI 会话与编排共用；非游客临时面板仍在离开后清除 Key。 |

**网页游客的生命周期。** 普通站内导航和切换模块继续使用同一份内存数据；刷新、关闭页面、退出游客或清空重开后，不能恢复上一轮内容。网页前进／后退缓存恢复会结束旧游客空间。图片和程序资源的缓存不等于保存学习数据。

**Android 游客的生命周期。** 游客进入同一套正式主界面，并拥有独立的内存状态。退出游客、承载界面销毁重建（包括旋转等导致的 Activity 重建）或进程结束后清空；仅切到后台、且界面和进程未销毁时，本次数据仍在。它不使用账号数据库或磁盘偏好文件保存游客内容，不能作为资料备份。

用户主动导出文件或复制到系统剪贴板的内容属于用户自行保存的副本，不会随游客退出自动删除。登录不会自动接收游客草稿；需要保留的内容应在结束前主动导出。

**网页侧重整理。** 宽屏提供课程、图谱、笔记、报告及 AI 资料的工作区，支持长文本编辑和导入／导出。**Kotlin 移动端侧重随身使用。** 正式主界面的课程、任务、笔记、AI、编排与设置保持触屏布局；既有本机课程、课表等入口在游客状态下改用独立内存数据。

两端共用星际像素角色、星球图标和配色，按屏幕调整场景比例与布局。当前共享资源共 44 张 PNG，其中 29 张为完整场景及入口原画；按钮和文字保持真实控件。移动端仍是 Kotlin Android，不是原生 HarmonyOS 应用。

## 04 模型与发送范围

API Key 是模型服务商签发的访问凭据，课灵账号密码不能替代它。临时配置目录预设 17 个服务入口：DeepSeek、阿里云百炼、月之暗面 Kimi、智谱、硅基流动、火山方舟、腾讯混元、华为云 MaaS、OpenAI、Anthropic、Google Gemini、OpenRouter、百度千帆、MiniMax、xAI、Mistral 和 Groq。目录入口存在，不等于每个模型都已开通或实测。

使用时先选择服务商和官方地域，再点击验证并获取模型。课灵只向用户选定的服务发送 Key，不自动向多家服务试探。部分前缀可以提供本地格式候选；普通 `sk-` 等格式无法可靠判断厂商，候选也不能证明 Key 有效。服务不支持目录或列表缺少已开通模型时，可以手填模型 ID。

游客 Key 只保留在本次内存，允许在设置、完整 AI 会话和智能编排之间共用。退出、刷新或所属游客状态销毁后清除。服务器只接受受控的官方模型地址，不能用一个自填地址把 Key 转发到任意网站。公开试用模型须由管理员单独开启，不能借游客入口使用未公开授权的账号密钥。

| 入口 | 问题与历史 | 可发送的资料范围 |
| --- | --- | --- |
| 完整学习会话 | 单次问题最多 6000 字符；最多最近 10 轮成功会话，历史合计最多 24000 字符。 | 单篇笔记最多 6000 字符；单项任务说明最多 4000 字符；单门课程最近最多 6 个知识点，每个最多 1000 字符，另附课程说明。 |
| 允许自动检索的会话 | 用户主动开启检索后才读取候选摘录。 | 最近 24 个知识点及 12 篇笔记中选择最多 6 条；没有全库向量数据库。游客语义检索使用本次 Key 所属服务的向量模型，会产生额外模型请求。 |
| 独立单次 Key 问答 | 单次问题最多 4000 字符，不读取完整会话历史。 | 明确勾选最多 3 条，正文各最多 2000 字符，标题各最多 120 字符。 |
| 游客智能编排 | 学习目标、目标日期、每日可用时间及规划／复盘方式。 | 所选课程检索到的最多 8 条资料，以及该课程的本次任务记录；不读取登录账号的资料。 |

聊天模型用于回答，向量模型把文本转换成可比较的数字以检索相关资料。模型目录中的“能力未知”不会被当作已验证支持；是否可用取决于实际授权、模型协议和配额。

“应用不持久化游客内容和 Key”描述课灵的数据层，不意味着网络基础设施或模型商没有运行日志。真实发送前需阅读内容处理及可能计费说明；不要提交不适合外发的材料。当前没有有效 Key，真实目录、回答、向量效果、计费和各厂商连通性仍未实测。

## 05 竞赛适配与产品边界

项目目标为 2026—2027 届华为 ICT 大赛创新赛。已有华为云 MaaS 模型入口、AgentArts 账号学习编排适配，以及资料、计划预览、用户确认和任务执行的结构。游客通过无状态模型请求生成计划，不创建云端学习记录；不能把这种路径称为已经实测 AgentArts。

当前预览使用 Vercel 与 Neon，不是华为云部署。适用赛区、赛题、报名、提交材料与评分细则仍须以本届正式规则为准；历史省赛材料不能替代本届要求。赛事依据和已知边界见[竞赛核验记录](competition/huawei-ict-2026-2027.md)。

课灵的设计取向是将一次学习中的资料、问答、笔记、计划和执行接起来，提供不注册也能使用完整界面的入口，并保留用户选择模型的空间。这些是可核查的实现和定位，不等于已经通过真实学生评测证明优于成熟竞品。语音、拍照、多模态资料、全库向量检索及真实学习收益等未完成或未验证能力，不因“全功能游客”而变成已交付能力。

视觉和开发使用了 AI 辅助工具。用于比赛时，应依据最终适用规则披露使用范围，由提交者核对事实、解释实现、复现结果并承担作品责任。

## 06 开始使用与验证状态

打开[游客入口](https://keling-ict-preview.vercel.app/trial)，进入完整学习空间。建议先创建一门自己的课程和一篇笔记，切换到其他模块再返回，观察内容仍在；结束前主动导出需要保留的内容，刷新后确认旧内容不再恢复。没有 Key 时，可以检查资料和日常功能，不能据此声称已验证真实 AI。

需要长期保存时，从[账号入口](https://keling-ict-preview.vercel.app/login)登录或注册。网页和手机必须使用同一个后端及账号才能共享已保存内容；游客空间不参与此同步，也不会自动转存。普通账号的现有功能差异与限制参见[Web 清单](WEB_FEATURE_INVENTORY_2026-10-30.md)和[Android 清单](ANDROID_FEATURE_INVENTORY_2026-10-30.md)，历史清单不是本次新增游客模式的验收报告。

3.2.4-preview 的 Android 版本码为 14。新版 APK 的最终路径、大小、签名及构建状态，以[本次交付记录](FULL_GUEST_2026-10-30.md)为准；旧 3.2.3 APK 不包含本次完整游客升级。当前为调试预览构建，不是应用商店正式签名版本。

已知本次验证：服务端 48/48；游客数据测试 10/10；游客整合测试 6/6；游客 AI 客户端测试 8/8；Web 构建通过，ESLint 0 错误／36 警告。测试涉及内存隔离、版本、幂等、取消、迟到响应和计划约束，其中模型响应均为合成测试数据，不能代替真实厂商调用。最新浏览器操作、Android 完整构建／新增测试及 Vercel 发布的最终结果，统一记录在本次交付记录中。

真实 AI、AgentArts、Android 真机及跨设备实际操作尚未取得本次验收证据。每小时迭代任务与计划已彻底取消；本次是用户明确要求的有限功能补丁，不恢复自动化。当前源码与预览下载归入 [KeLing4.0 仓库](https://github.com/Hyhyhyyy/KeLing4.0)，原项目保留来源说明。
