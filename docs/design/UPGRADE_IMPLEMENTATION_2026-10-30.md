# 课灵游戏化升级实施与证据

本记录跟踪用户指定总设计的落实，保留实施顺序与验收边界。4.0.0-preview / Android code 16 的首章代码、共享规则、双端入口和本地构建已完成，正式库已应用增量迁移；公网部署与同版本 Release 以[本版交付记录](../history/2026-10/GAMIFIED_UPGRADE_2026-10-30.md)的确认状态为准。3.2.5 是上一已发布基线，不能用其运行截图证明 4.0 已通过界面验收。没有周期性自动迭代任务。

## 实施顺序

1. 固定端云数据合同、历史余额快照、证据和奖励规则。见 [端云合同](EXPEDITION_CONTRACT_V1.md)。
2. 完成二叉树首章的 18 道原创变式、三个学习目标、路线修复与教星芽两种玩法、反馈和一次基地建设；Web 与 Kotlin 使用同一合同和测试数据。
3. 接入文字、Markdown、文字 PDF 材料，保留版本、段落、页码和内容摘要；材料修改后中止仍依赖旧版本的未完成关卡。知识图候选需用户确认。
4. 增加基于选定资料的 AI 辅导与受日程约束的计划预览。模型文字不能改变证据、奖励或任务；写入由明确确认触发。
5. 验证账号离线草稿、接管和版本冲突；游客使用同样界面和规则但仅在内存保存。旧功能均保持入口可达。
6. 构建、自动化检查、可用运行环境中的操作验收后发布；最后准备官方要求的提交文档、真实画面包与 3–5 分钟视频设计。
