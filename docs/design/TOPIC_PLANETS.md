# 主题知识星球

主题输入不局限于学校学科。可以输入网络用语、抽象概念或多义词，并补充已有基础、想了解的语境与目标。语境可选综合辨析、通识原义或网络文化。默认生成12题，也可选6题或18题。

## 从检索到可查看的星球

服务端先从联网搜索获取标题、网址、摘要和可用的时间信息，再将实际返回的资料编号交给模型。没有足够资料或检索不可用时停止生成，不用模型记忆冒充搜索。资料是搜索摘要，网页本身仍可能片面、过时或错误；“取得资料”不等于“事实已被证实”。

模型依据主题、基础和资料生成义项辨析、比较与边界，组织学习区域和练习，同时生成知识图谱。图谱节点数、分支数和层级按内容决定，层级关系与跨分支关联分开显示。节点可以查看摘要和对应来源，在确认创建星球之前即可浏览。为控制请求体与手机绘图规模，一颗星球最多48个节点、96条关系。

确认后，完整图谱保存在星球记录中；课程知识图谱还会得到同一批实际节点及层级关系。跨分支关联和关系标签保留在星球全图中，普通知识图谱编辑器仍沿用既有父子关系数据结构。

## 六种题型

单选与多选通常各有4至6个选项。判断题固定两个选项，填空接受列出的文字变体，排序比较完整顺序。简答先提交自己的表述，再对照参考答案及核对要点手动自核；系统不把这一步称为模型判分。客观题也只是与生成的参考答案比较，不构成经过教师审定的知识认证。

区域先修关系同时约束客观题完成和简答自核。修改上游题目后，下游完成状态会依据先修条件重新计算，其他题的作答仍保留。

## 对生成结果继续提要求

每道题可单独填写修改要求，例如“改成多选，增加一个常见混淆项”或“保留知识点，换成生活情境”。服务端只替换目标题并分配新的题号，保留其余题目与图谱，原题作答清除。生成失败、来源或答案格式校验失败时保留旧内容。保存后的修改按账号校验，并通过请求编号防止重复写入；另一个设备已改动内容时会要求刷新。

定制星球形象由实际绘图服务根据主题、义项与学习区域绘制，也可单独追加视觉要求重新生成。失败时显示默认星球或保留上一幅形象；不会把默认素材标成新生成图。形象是主题插画，不是事实依据。

## 代码入口与复现

生成入口是 `POST /api/learning/v1/planets/generate`，长任务返回编号，再查询 `generation-jobs/:id`。`topicResearch.ts` 整理实际搜索结果，`planetEnhancement.ts` 组织生成约束，`planets.ts` 校验并签署预览。`packages/shared/src/planet.ts` 负责两端一致的题型、来源、图谱和作答规则。预览修改使用 `regenerate-preview`，已保存星球使用 `/:id/regenerate`。

妙搭实例分别承担整星球结构化生成、单题结构化重生和星球形象生成，注册代码位于 `deploy/miaoda/server/modules/gateway/`。本地未配置真实搜索或模型时应返回未连接错误；隔离测试里的合成返回只证明接口和状态规则，不证明真实模型效果。线上检索与实际生成结果另见对应日期的验证记录。
