# Web 首章远征实现与验证说明

本文件描述当前工作区新增的 Web 实现，不表示已发布或完成真实用户验收。产品版本与发布状态以项目发布记录为准。

## 使用路径与保留功能

主导航为远航、星图、基地、我的。原课程、任务计时、知识图谱、笔记、AI 会话、智能编排、个人资料、学习报告、签到与设置仍保留；原首页位于 `/workspace`。游客与账号使用相同界面和功能入口。

| 入口 | 当前行为 |
| --- | --- |
| `/` 远航 | 选择课程与短／中／长候选；10 分钟启动单目标路线，20 分钟启动教星芽，25 分钟启动三个目标试炼。候选是预算建议，不承诺学习所需时间；已有未完成远征优先接续。 |
| `/greenhouse` 星图 | 保留课程列表、十款星球外观及课程编辑。课程详情新增二叉树示例章节入口。 |
| `/greenhouse/:id/chapter` | 三目标地图／等价列表、训练／独立尝试、原创材料、回访、试炼、资料导入、资料辅导与远征历史。 |
| `/voyage/runs/:id` | 真实队列／栈操作或键盘顺序输入、BST 全祖先范围判断、解释与自核、提示、提交、反馈、下一步、暂停／恢复／结束、原答案与操作日志回放。 |
| `/base` | 一个建设位置，三种明确价格的装饰；显示实际余额，购买与装备由确认结果决定。可回看、修订、删除“我教星芽的知识”自述档案。 |
| `/me` | 本机体验偏好、线下学习自述及分页历史、原有个人与学习入口、历史规则快照。 |
| `/voyage/evidence` | 来源版本、过程证据、原答案入口，单独展示投入奖励与建设购买流水。 |
| `/voyage/sync` | 待同步、冲突、失败、本机草稿、显式停止重试与不含密钥的草稿导出。 |

新场景使用三张独立的 `expedition_voyage.png`、`expedition_starmap.png`、`expedition_base.png`；基地在完整场景的建设台上叠加对应透明装饰。树节点有当前／已访问状态和文字等价说明，回放按按钮步进，装备依确认结果变化；仅在操作导致状态变化时使用一次短淡入或轻缩放，同时遵守系统低动效与本机偏好，无持续闪烁。代码有窄屏、换行、44px 控件、键盘焦点与低动效样式，但本轮未进行浏览器视觉验收。

## 学习与证据的边界

Web 游客和服务端复用 `@keling/shared/expedition`，不在界面中另写奖励公式。首章为 BFS 队列、DFS 栈、BST 完整取值范围三个目标，十八道原创种子题。规则结果、自述和 AI 建议分别显示。

种子内容仍待独立人工审核；程序检查通过不等于严格知识徽章。一次学习循环需要实际作答、查看反馈并确认下一步；重复操作与重复目标不会重复发放奖励。三个不同目标的有效循环可以获得首次天线建设所需的六枚结晶。线下自述独立记录真实投入，每个学习日前五次各 2 经验，不授结晶；同日同内容去重，不作为客观知识证据。

暂停状态与时间来自共享规则。界面显示最近确认的会话经过、暂停和未暂停会话时间，明确它们不是实际学习时长，也不是奖励依据；关闭页面、切换应用或休眠不自动解释成学习。

伙伴提示频率控制通用步骤说明，题目的实质提示仍需主动请求。叙事浓度调整学习标题与情境说明；低动效减少过渡和伙伴说明。这些偏好只保存在本设备的当前账号空间，游客只在本次内存保留，未声称跨端偏好同步。

## 资料、AI 与计划的调用链

`MaterialsPanel` → `learningMaterials` → `/learning/v1`。TXT、Markdown 和文字 PDF 先显式提交无状态解析，显示原文、警告与片段，再确认保存不可变版本。更新需要旧版本；原引用保留。内置 `SEED` 材料只读。提取的知识点候选由用户编辑并确认加入原课程图谱，不称作模型生成的已审核关卡。

资料辅导先预览实际片段，再同意发送给用户配置的模型。游客至多发送三段摘录，不携带账号凭证；账号使用服务端检索与辅导接口。回答展示实际来源，返回及保存笔记前核对资料仍为当前版本。Key 不写入远征草稿、队列、导出或 IndexedDB。真实模型因缺少有效 Key **未实测**。

远征内的 AI 求助先记录 `HINT`，再打开带课程与题目片段的正式 AI 会话；请求尚未同步时不跳转或调用模型。课程上下文的预览显式包含至多三个当前资料首段、目标过程、末两条已确认自述及最近三次远征摘要，不包含写入令牌、其他课程或隐藏草稿。模型本身不能发奖励或修改学习结论。

`SchedulePanel` → `learningSchedule` → 约束排程接口。填写日期、每日预算、可用时间、休息及排除日期；预览三个 25 分钟学习单元与未安排事项后，才确认加入原任务模块。显示北京时间，保留已有任务，不称作 AI 输出。游客确认前核对课程、任务、有效期；整批任务在一次同步内存操作中写入，重复确认不再次创建。

## 保存、离线与接管

`expeditionStorage` 为账号在 IndexedDB 分别保存快照、作答草稿、待提交操作和本设备标识。游客使用独立 RAM 容器，结束游客会话即清除；不自动转存登录账号，也不跨设备同步。

一次命令同时携带操作编号、预期版本及设备写入资格。操作编号用于识别重试，预期版本用于发现其他设备的修改。客户端先保存原命令，再发送；超时后沿用原编号和答案重试。版本冲突会停止后续队列，不自动改写答案或预期版本。用户可明确接管本机、刷新云端记录、核对草稿，或停止该项重试；停止重试不会撤销服务端已经接受的操作。

恢复原回执时不会降低已知的课程版本、远征版本或余额版本。账号变化后迟到的响应不能进入新账号。首次离线进入只接受此前服务端验证过、且与当前登录凭证指纹精确匹配的本机身份缓存；HTTP 拒绝不触发离线身份回退。缓存不授予任何服务端权限。

离线保证聚焦于已读取的远征快照、作答草稿和明确排队的远征命令。首次未缓存资料、模型请求、资料导入或新排程需要联网；未宣称所有既有功能均可离线使用。

## 本轮可复现验证

```sh
npm run test:expedition --workspace apps/web
node --test scripts/test-guest-ai.cjs
npm run lint --workspace apps/web
npm run build --workspace apps/web
```

新增 Web 测试 **25/25**：6 项 IndexedDB 持久与隔离，7 项游客共享规则／学习循环／租约／自述／实际容器操作，6 项请求丢失与重试／冲突／版本／账号／离线身份，6 项资料版本／候选／迟到响应／排程原子性／课程 AI 上下文。旧游客 AI 的 8 项回归亦通过。客户端请求测试使用合成传输，不调用真实模型；存储测试使用 `fake-indexeddb`，不等同真实浏览器存储验收。

Web TypeScript 与 Vite 构建通过；lint 为 0 错误、34 警告。共享规则、服务端与 Android 验证由相应记录单独说明，不将它们当成 Web 浏览器验收。

仍未验收：实际浏览器视觉、320px／390px 与字体放大实测、读屏体验、不同浏览器 IndexedDB／PWA 生命周期、真机跨端接管、真实模型连通、真实学生学习效果与性能分位数。当前实现是可执行首章，不代表大纲全部后续研究、社交或原生鸿蒙工作已完成。
