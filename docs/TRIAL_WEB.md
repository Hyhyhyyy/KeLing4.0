# Web 完整游客模式

版本：3.2.4-preview，2026-10-30。当前入口为公开 `/trial`，通过 `App.tsx` 的游客启动入口进入正式应用主界面。原 `pages/Trial/Trial.tsx` 的五模块独立示例页不再承担当前游客入口；旧测试和截图只说明旧版行为。

## 当前体验

未登录访客可从公开首页、登录／注册页进入游客空间，使用正式导航和各页面。课程与知识图谱、任务与专注、笔记、学习会话、智能编排、报告、签到、成就、资料设置和视觉资源入口均不再因未登录而锁定。这里的“完整”指复用当前应用已实现的功能，不代表原应用尚未完成的能力已被补齐。

普通站内导航保留本次课程、知识点、任务、笔记、签到与学习统计，也保留本次会话和模型配置。示例课程明确标为示例，初始学习时长及奖励为零。用户可以新增自己的资料；不是只有固定演示内容可点击。

## 数据与身份边界

`services/guestSession.ts` 管理当前文档中的游客身份；`guestData.ts` 保存课程、节点、任务、笔记及用户状态；`guestAI.ts` 保存会话、回答、规划与请求控制器。它们均不使用浏览器持久存储保存游客数据。

`services/api.ts` 在游客模式拦截学习 API，执行内存操作；未实现的游客 API 明确报错，不回退到账号 API。账号 token 不附带到游客请求。`useAppStore.ts` 和主路由共用正式 UI，并在身份变化时隔离旧响应。游客开始后不读取账号课程，也不覆盖原有账号数据。

刷新、关闭页面、退出游客或清空重开会结束当前空间。浏览器前进／后退缓存恢复也结束旧空间。站内切换模块不清空；静态图片／程序缓存不包含学习数据。用户主动下载的导出文件、复制到系统剪贴板的内容不会被应用自动删除。

登录不会自动迁入游客资料，游客内容也不跨端同步。需要长期保留时，应在结束前主动导出，然后在账号模式整理；“保存到本次笔记”不等于云端保存。

## 完整 AI 与编排

完整游客 AI 复用 `StellarAssistant.tsx` 的会话界面，支持新建、切换、搜索、取消、删除、导出及回答保存。课程、已保存笔记与任务可以准备资料问题，发送前预览和校验版本。没有有效配置时提示输入 Key，不显示伪造模型答案。

`ModelAccessPanel` 提供 17 厂商目录、Key 格式候选、用户明确触发的实时目录获取及手填模型。游客 Key 在本次内存跨设置、AI、编排使用，退出或刷新清除；格式候选不等于认证，不向多家厂商试探。

完整会话每次问题最多 6000 字符，保留最多最近 10 轮成功历史且合计不超过 24000 字符。单篇笔记摘录最多 6000 字符；单项任务描述最多 4000 字符；单门课程最多 6 个知识点、每个 1000 字符。主动开启检索时，从最近 24 个知识点和 12 篇笔记选择最多 6 条，游客向量检索使用当前 Key 所属厂商的向量模型。

智能编排根据所选课程资料与本次任务记录生成计划。服务器校验日期、每日总分钟数和来源；用户确认时再次检查本次资料是否仍存在、版本是否变化。只有确认后才添加本次任务，重复确认不重复添加，失败回滚也限于原游客空间。

## 无状态服务调用链

学习 CRUD 在浏览器内执行；只有用户明确发起真实模型请求时，才将指定内容交给服务端转发。AI 服务没有游客学习数据库或后台持久会话。

- `GET /api/trial/workspace/catalog` 只返回管理员明确开启的公共试用模型，不泄露账号模型 Key。
- `POST /api/trial/workspace/chat` 接收所选 Key、模型、问题、允许的历史及资料范围；返回回答、用量与实际引用摘录。
- `POST /api/trial/workspace/plan` 接收学习目标、所选课程资料和本次任务，返回经约束校验的计划，不写任务。
- `/api/model-access/catalog`、`discover` 保留厂商目录与用户触发的模型发现。独立单次问答仍通过原 `/model-access/complete` 处理。

请求使用 `credentials: omit`、`cache: no-store`、`redirect: error`，不附带账户认证；限流、长度校验、厂商地址限制和超时继续生效。没有用户 Key 时，仅能使用显式开启的公共试用模型，不能借游客入口消耗未开放的部署模型权限。

退出游客会取消挂起请求；迟到回答不能写入新空间。停止等待不保证模型商停止处理已送达请求。应用不持久化内容不等于网络基础设施或模型商没有运行日志。
