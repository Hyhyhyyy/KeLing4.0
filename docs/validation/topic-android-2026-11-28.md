# 任意主题与多题型 Android 验证

后续已完成真实云端原生回读，并修复首次图谱适配后升级至 33 版；见 [云端回读记录](topic-android-cloud-2026-11-28.md)。下文保留 32 版初次编译时的验证范围。

本轮候选包为 **4.3.0-research-rc1 / versionCode 32**。原生端支持综合辨析、通识原义、网络文化三种语境，6、12、18 道题，以及单选、多选、判断、填空、排序和简答自核。简答先展示参考答案与核对点，用户再次确认同一份回答后记录自核；不把自核称为模型评分。

生成预览和已保存星球都直接读取 `draft.knowledgeGraph`，通过两端共用的 X6/Dagre 显示完整节点、层级边、关联边与关系名称。预览为只读，点击节点可查看摘要与来源。只读桥接层拒绝编辑、布局保存事件；图谱加载超过 15 秒显示错误及重试入口，不用区域框替代失败图谱。确认后课程编辑器保存实际知识节点与层级，关联关系仍在星球完整图谱中保留。新增测试使用七个节点、七条关系验证，未把三个学习区域派生成三个假节点。

形象显示优先使用服务端返回的公网 HTTPS 生成图，加载失败使用原有学科形象。生成时可关闭专属图像；预览和已保存星球均可输入要求重绘形象或重生单题。失败保留原内容。单题重生按新题目编号清除该题作答，保留其他作答，并重新计算先修链；游客走签名预览接口、只更新本次内存。

确认及预览重生直接透传服务端原始草稿 JSON，避免 Android 解码后丢失新增字段或默认空列表而破坏签名。没有原始 JSON 的兼容路径使用显式默认值且省略未提供的可选 null，相关测试同时检查来源、多义分析、图像元信息和未来未知字段。
