# 知识图谱布局保存验证

日期：2026-11-27。范围：共享服务端布局保存、版本冲突、所属账号检查和保存状态；不包含 X6 页面交互或发布后的 PostgreSQL 验收。

## 接口与调用链

实际启用入口为 `apps/server/src/index.ts` → `routes/knowledge.ts` → `controllers/knowledge.ts` → `services/knowledgeLayout.ts`。

`PUT /api/knowledge/:courseId/layout`，使用现有账号认证。请求格式：

```json
{
  "positions": [
    {
      "id": "从节点接口取得的节点ID",
      "positionX": 0.25,
      "positionY": 0.75,
      "expectedUpdatedAt": "从该节点updatedAt取得的ISO时间"
    }
  ]
}
```

坐标为 0–1 的有限数值，两端编辑器用逻辑坐标除以 4096。每批 1–500 个唯一节点，均须属于当前账号的指定课程。客户端同时提交每个节点的原版本时间；任一版本已变化时整批返回 `409 / LAYOUT_CONFLICT`。无权限、节点不属于课程或节点已不存在返回 `404 / NOT_FOUND`；坐标、数量、重复 ID 或版本格式无效返回 `400 / VALIDATION`。

成功返回请求顺序的 `nodes`，包含实际保存后的坐标、新 `updatedAt` 和解码后的父子节点 ID 数组。客户端应采用响应的坐标和时间，不能沿用旧版本再次提交。

`GET /api/knowledge/:courseId/nodes` 与保存响应还返回：

- `savedNodeIds`：当前坐标与明确保存标记一致的节点 ID。
- `layoutSaved`：当前课程所有节点均在上述集合时为真，空图为假。
- `layoutUpdatedAt`：最后一次明确保存布局的时间，无记录时为 `null`。

这些字段区分初始自动布局预览、用户保存到中心点的布局，以及新加入节点与已保存节点混合的状态。仅缩放、适配视图、拖动本地预览或保存失败，客户端都不应自行宣称已云端保存。

## 原子保存与状态隔离

事务先取得账号写锁，校验课程归属、全部节点和版本，再用一个参数化 SQL 批量更新坐标。SQL 再次匹配各节点版本，防止校验后变化。更新数量不足、后续保存标记失败或其他异常会回滚整批变更；节点正文、关系、掌握度和奖励均不参与更新。

保存标记使用现有 Note 表的内部类型 `KNOWLEDGE_LAYOUT_INTERNAL`，不增加字段或迁移。标记采用数据库实际回读的坐标，避免小数表示差异造成错误的“未保存”状态。普通笔记列表、编辑、删除、计数、AI 上下文、检索和规划来源均排除此内部类型。删除课程只清理该课程的布局标记；账号删除仍遵循 Note 的既有级联关系。

## 节点编辑后的关系保存

实际路由中的单节点更新曾忽略 `parentIds` 和 `difficulty`。现已由 `services/knowledgeNodeEdits.ts` 统一处理单节点创建与更新：`PUT /api/knowledge/node/:id` 保存前置知识、1–5 整数难度、名称、描述、自评掌握度、解锁及坐标；`POST /api/knowledge/:courseId/nodes` 采用相同校验，0 坐标不再被默认中心点替代。掌握度仍是用户自评，不是系统认证。

前置节点须属于同一课程，重复、自引用及新形成的循环返回 400，外部或不存在的节点返回 404。事务内同时更新前置节点的 `childIds`，严格推进受影响行的版本时间；并发关系编辑共享账号锁，不能各自校验通过后一起形成循环。既有创建请求的 `childIds` 仍可使用，并同步对应子节点的 `parentIds`。

单节点删除也在同一账号事务内清理本课程的父子引用，并推进受影响节点的版本。否则删除前置节点后，剩余节点仍会携带已失效 ID，导致下一次编辑无法保存。其他课程的节点不参与清理。

`apps/server/tests/knowledgeNodeEdits.test.cjs` 新增 3 项验证：实际 HTTP 编辑后重新读取全部字段及双向关系；非法请求无部分写入；删除前置节点后剩余节点仍可编辑且其他课程不变；旧创建子关系兼容；两次并发前置编辑只有一个成功。旧批量导入逻辑不在本次修改范围。

共享编辑器及两端包装的只读复核确认：坐标按 4096 归一并保留数据库回执精度；保存失败保留草稿；409 后可明确放弃草稿并重新读取；响应显示课程中另有未加载节点时会重新取得全图并保留待保存状态。以上为代码检查，不代替设备交互结果。
