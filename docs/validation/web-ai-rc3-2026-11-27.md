## 调用链与失败路径

Web 普通会话沿用服务端会话及运行接口。游客公共问答、游客计划和资料导师通过 `services/aiJobs.ts` 兼容同步响应与 `202` 任务响应，再读取 `/api/ai-jobs/:id`；游客传不透明任务令牌，账号传自己的登录令牌。模型调用失败、任务过期或网络错误会显示真实错误，不生成替代答案。停止等待保留输入，不宣称撤销已经发往模型服务的计算。

资料问答发送前、接收后和保存笔记前都校验资料版本；失效来源不能直接保存为当前辅导结果。自带 API Key 保持现有内存存储方式。课程资料和排程面板现显式载入共享样式：线上输入框高 48.39 px、圆角 6 px，字体为华文中宋。

## 验收中观察到的问题及处理

第一次资料脚本在异步引用预览结束前勾选同意，预览回写后取消了该勾选。修正脚本为等待引用片段出现后再确认，真实导师调用随后成功。不是通过绕过确认按钮取得结果。

旧 RC2 规划 UI 的自动等待没有观察到终态；后续正式读取证实该 AgentArts 运行已成功。过程中附加请求曾返回纯文本 `Too many requests`，但该次未保存 HTTP 状态，不能据此断言为模型失败或确定限流来源。旧运行结果仅作为历史证据，最终计划验收使用 RC3 的 Miaoda 运行，并使脚本遇到页面错误立即记录退出。

基础回归为根游客 24 项、Web 工作区 53 项、更新与离线导航 8 项、图谱 5 项，共 90 项通过。最终样式与版本调整后 Web build、更新测试 8 项及真实浏览器样式检查通过；lint 为 0 错误、26 项既有 any 类型警告。本轮没有通过修改学习奖励或伪造掌握度来获得展示数据。
