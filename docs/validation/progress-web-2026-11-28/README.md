# Web 阶段进度与同源星球形象验证

2026-11-28，目标版本 4.3.2-progress-rc1 / Android code 34。本目录是本地浏览器合成接口验证，**没有调用真实模型，不代表线上生成已经成功或已测得提速**。真实链路与发布由同轮发布记录单独报告。

## 实现

- `packages/shared/src/planetWork.ts` 定义工作类型、阶段、状态、活动和 revision。`parsePlanetWorkProgress` 丢弃未知状态、重复阶段、非法日期及自由文本扩展，进度不进入原草稿签名。
- `services/planets.ts` 将初始响应与每次轮询中更高 revision 的进度传给页面；旧接口没有进度时只显示不定动画。首次生成、图像重绘、单题重生和相似碎片共用此路径。
- `PlanetWork` 以薄荷完成段、金色活动扫光和星芽轨道显示工作状态；只有服务端 `completed` 才填充完成段。`skipped` 为灰色纹理，不能称作绘图成功。支持同时运行的阶段，不按时间增加百分比或预计剩余时间。系统减少动效与应用已有减少动效设置均会停止装饰动画。
- `useCoursePlanets` 一次列表按 `courseId` 关联记录，首页、课程星图、课程详情、星球列表共用；同一空间并发列表合并，请求结束不长期缓存。确认与重绘后通知刷新，窗口重新聚焦/可见时读取远端。账号和游客空间隔离。
- 已生成的有效图片地址加载失败只显示载入/重试占位，不换成另一颗固定插画；没有定制形象的旧课程仍用原有插画。

## 结果与证据

- Web 回归：24 + 75 = **99 项通过**。新增覆盖进度防御校验、重复/过期 revision 不前进、旧同步接口不捏造阶段、列表合并与重绘后更新。
- Web TypeScript/Vite/PWA 构建通过；ESLint **0 错误 / 26 项既有警告**。
- Chrome 桌面 1440×1000、手机 390×844，合成接口完成 4 种操作。等候 2.2 秒期间轨道实际变化，但完成环节仍为 2/6；两个并行阶段同时显示。系统减少动效时动画名为 `none`。
- 手机无横向溢出，JavaScript 页面错误 0；相似生成等待时“问星芽”按钮可用，未提交答案在完成后保留。
- 重绘后星球详情、课程详情、星图和首页读取同一个新 URL；人为模拟图片请求失败后出现占位，点击重试成功。
