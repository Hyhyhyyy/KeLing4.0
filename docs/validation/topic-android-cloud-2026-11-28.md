## 发现与修复

32 版图谱首次出现时为 10% 并靠左上角，点击“全图”才变为正确居中的 17%。原因是预先组合的 WebView 先收到图谱、后获得有效画布尺寸；X6 自动调整尺寸，但不会重算此前的缩放和平移。

共享引擎现在在下一绘制帧读取有效尺寸并适配全图，尺寸观察器补偿首次布局。用户触碰画布、使用滚轮或点击缩放/全图后，自动适配停止，后续尺寸变化不会覆盖用户的视图。没有修改图谱节点、关系、来源或作答数据。

覆盖安装 33 版后，原有登录仍有效。首次打开和从顶部再次滚入图谱均自动显示居中的 17%，12 个节点都位于画布内；点击放大变为 32%，继续滚动仍保持 32%；点击“奶龙抽象二创”显示实际摘要和两条来源。只读预览没有编辑、保存或自动布局按钮。

同版最终冻结前另将共用忙碌提示改为中性的“请稍候…”，避免仅 GET 读取星球时宣称正在检索或绘制。该修改仅替换一处文字，重新构建并校验安装包；没有新增测试或重开模拟器。下列运行截图摄于这项纯文案调整之前，图谱和题型逻辑未变。

独立 Chrome 固定数据回归将 iframe 初始高度设为 0，随后改为 380 px。12 个测试节点全部进入画布，自动缩放为 15%；手动放大为 30%、拖动画布，再把宽度从 304 px 改为 390 px，缩放和平移保持不变。这是布局回归，数据不是模型生成证据。
