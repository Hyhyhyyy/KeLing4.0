## 接入怎样工作

网页经现有 Agent API 进入 AgentService。prepare 验证当前用户、课程和考试日期，建立运行记录；execute 在 inline 模式调用现有 tool，从数据库检索资料和任务状态，保存来源审计，将结果转换成 context JSON 字符串后交给华为云。入站密钥只由服务器使用。

runtime.ts 读取事件流，计划仍受日期、每日总时长和实际来源校验约束；学生确认后才通过事务创建任务，重复确认不重复写入。复盘上下文携带已有任务完成状态和用时。回调模式保留工具密钥要求。本轮未改变数据库结构。
