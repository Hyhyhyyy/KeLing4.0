# 自选学科知识星球：本轮验证与使用

版本：4.1.0-planet-rc1 / Android versionCode 28。日期：2026-11-27。

## 本轮六项任务

1. 开场故事：四幕星芽引导；结尾使用用户指定句“让我们一起一步一步探索这个知识星球的每一方寸文明！”。
2. 学科生成：空白初始化，输入学科、基础与目标；真实模型生成学习区域、短讲解与单选练习，结构校验后预览确认。
3. 多端流程：Web、桌面PWA与Kotlin Android接入生成、探索、解析、日志、后续任务与账号重开。旧账号记录保留，示例二叉树主动选择。
4. 学科原画：12类常见基础学科；原稿、无损WebP、语义别名与图集坐标统一在assets/stellar。其他学科可生成，使用通用图形。
5. 答辩PPT：故事化标题；外圈数学/英语/历史/计算机/经济/政治，内圈语文/物理/化学/生物；两圈按各自90度圆弧等分并留间距；独立致谢末页。完整画面和可编辑标注保留。
6. 发布与复核：本文件先记录本地验收；最终在线发布、仓库提交和安装包校验在release-planet-rc1-2026-11-27.json记录，不将准备完成当作已发布。

## 怎样复现

打开应用，选择游客体验或登录账号，进入“选择第一颗星球”。写下学科，例如“初中地理”，设置学习起点和目标，选择课灵公共模型后生成。看到预览后再确认启程；阅读区域讲解，作答并查看解析，保存航行日志，新增后续任务。回到星图可重开同一颗星球。

游客内容在当前会话内保存，结束游客会话后清空；账号模式把课程、题目和作答进度保存在服务端，供另一端使用同一账号读取。模型失败时保留输入并提供重试，不替换为固定示例。

## 实现与证据

- 入口：Web apps/web/src/pages/Planets；Android apps/android/app/src/main/java/com/keling/app/planet。
- 请求：/api/learning/v1/planets/catalog、/generate、/jobs/:id、/confirm、/:id/answers（准确挂载路径以server/src/index.ts为准）。妙搭适配器调用原生文本转结构模型；其他环境可使用配置模型或用户当次提供的模型连接。
- 校验：packages/shared/src/planet.ts限制区域、先修关系、题目选项与答案索引。预览带服务端签名，确认后在事务中创建课程、知识点和首项任务；重复确认和重复作答不重复记账。
- 保存：生成任务复用独立命名空间的AgentRun；星球记录使用内部Note类型，并从普通笔记、检索和规划资料中隔离。未变更数据库schema或迁移生产数据。
- 实际模型：planet-native-model-2026-11-27.json记录16.7秒生成初中地理、3区域和3题的真实响应。题目可依据课文回答，但生成文案仍存在概括过宽和解释方式需润色的问题，继续标记UNREVIEWED。
- 本地测试：后端95项；Web65项（24服务/会话检查+41界面与学习流程契约）；Android本轮100项基线后补隔离测试，以最终Android报告为准；托管适配15项。新素材64项清单与2项字体校验通过。

## 当前边界

通用学科目前是“短课文+单选练习+学习记录”，不是每个学科都拥有二叉树那样的专属交互玩法。图像是预先绘制的学科原画，模型生成的是学习内容，不把原画称为实时模型生图。

练习对错是对照生成答案的程序比较；没有把答对一题换算成权威掌握度或认证奖励。题目尚未完成教师审核，真实教学效果没有对照研究。妙搭模型成功不等于Huawei AgentArts、向量检索或全部聊天提供方已完成真实联调。Kotlin Android不是原生HarmonyOS，模拟器不代替实体设备。
