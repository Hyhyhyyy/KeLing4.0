## 清理策略

无论成功或失败，脚本在退出前重新确认当前 JWT 的用户 ID 和邮箱等于刚创建的隔离账号。只对私有状态中记录的 IDs 操作：关闭未结束的测试远航，删除测试任务、笔记，对导入资料写删除标记，删除测试课程及其知识点。不会枚举后删除其他账号的数据，也不直接执行 SQL。中途清理失败会标为 `CLEANUP_INCOMPLETE`。

本项目没有账号删除 API；隔离测试账号、操作回执、远航进度/奖励审计、资料删除标记与引用历史会留在该测试账号下。这是预先声明的残留范围，不能写成“生产库零残留”。删除这些审计记录需要单独的数据保留决策，本脚本不扩大删除范围。若网络中断导致写请求没有收到回执，不能保证已记录该次产生的 ID，应保留报告和隔离账号以便定位，不能声称已彻底清理。

只重试这个账号的清理：

```powershell
node scripts/smoke-online-api.cjs --cleanup-only --state .cache/online-api-smoke/<UUID>.private.json
```

私有状态路径必须位于本仓库指定缓存目录内；每次新执行都使用新账号和新状态文件，不允许把普通账号凭据替换进来运行。
