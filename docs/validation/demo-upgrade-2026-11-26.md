# 课灵演示功能升级验证

版本：4.0.6-defense-rc7；Android versionCode 27；二叉树章节 1.0.1。

本轮目标是让现有功能可操作、可恢复、可复现。下述测试不等于真实模型或教学效果验证。发布记录将在实际上线核验后补齐。

## 已修复的调用链

- Web 任务页 → 工作区数据层 → 任务 API：暂停、继续、切换任务累计真实计时；已成功写入后的读取失败显示重试，避免重复提交。实测还发现计时条遮挡完成按钮，已改为独立行。
- 导入资料 → 当前资料版本与片段 → 助手检索/规划依据 → 确认任务：资料无需先转笔记即可检索；资料替换/删除后，旧规划返回 PLAN_STALE；并发确认只创建一次。
- 知识图谱 → 共用节点/连线变换：缩放连线对齐，切课旧请求不会覆盖当前课程，读取失败可重试。
- 笔记编辑 → 版本检查：冲突后可读取最新或保存副本，保留草稿。资料导入成功后清理预览，防止重复提交。
- Android 工作区 → 任务/笔记 API或游客工作区 → 报告/成果：补任务创建删除、修复完成失败丢失时长、让统计读取当前工作区；补 TXT/MD 导入导出和返回历史。
- Android 顺序输入 → 保留原文 → 独立解析答案：不再吞掉末尾逗号。
- 二叉树题目 → 独立算法审计：18题计算一致；修复3题的提示/评分依据矛盾，版本递增，不改人工审核状态。

## 演示的真实边界

- 当前华为Runtime实际请求为HTTP 403，包含GetAppCredential超时及模板Error；控制台要求重新登录。真实模型问答、向量检索与AgentArts规划尚未通过本轮验收。
- 线上配置仅有AgentArts相关密钥，没有通用聊天/嵌入模型配置。规则排程和二叉树反馈是程序规则，不能称作已验证的模型推理。
- 18题humanStatus保持PENDING，讲解题只记自评；严格知识徽章没有擅自开启。
- 当前后端在妙搭、数据库在Neon；Android为Kotlin应用，不是原生HarmonyOS。
- 新章节1.0.1不继续结算旧1.0.0在途作答；旧记录保留，需新建一次远航。

复现入口：主仓库运行`node scripts/start-demo.cjs`，打开http://127.0.0.1:4173。每次创建独立SQLite，不继承云端密钥。真实API检查用`scripts/smoke-online-api.cjs`；默认只打印计划，执行模式与限定清理见同目录说明。不要把测试账号和手动测试时长用于教学效果宣传。
