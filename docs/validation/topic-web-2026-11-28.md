# 任意主题星球 Web 与共享契约验证

日期：2026-11-28。范围：本轮 Web、共享星球契约、X6 图谱预览。真实模型与线上发布另见本轮服务端和发布记录；这里的浏览器内容为明确标记的测试夹具，不能作为真实 AI 输出、实际生成图片或学习效果的证明。

## 输入、生成与预览

主题输入支持自动识别、常规知识、网络文化三种语境，题量支持 6、12、18 道。预览包含语义辨析、资料来源、定制星球图、知识图谱和可逐题展开的练习。单题与插画分别接收反馈并重新生成，未确认的草稿通过服务器签名令牌往返；页面不直接编辑已签名的图谱。

`apps/web/src/pages/Planets/Planets.tsx` 是页面入口；`apps/web/src/services/planets.ts` 负责生成任务轮询、保存、作答和重生。`packages/shared/src/planet.ts` 验证来源、题型、图片地址、图谱结构并处理本地游客作答。旧草稿缺省的新字段不会插入规范化结果，契约测试对旧 JSON 的完整字节进行了比较，避免已有草稿签名失效。

## 客观作答与自核

单选、判断比较选项；多选比较完整集合；排序比较完整排列；填空使用 Unicode NFKC、空白和大小写规范化后精确匹配。简答先提交文本并展示参考答案和核对点，随后用户明确自核，才记为自核完成。它始终不记为 AI 判定正确。改动文本会清除原自核，修改先修题会重新锁定依赖区域。

## 浏览器交互结果

隔离 Chrome 以本地 Web 和拦截的模型响应操作真实页面，测试数据写明“界面测试”，没有调用真实模型。实际完成：

- 六种题型分别填写、提交并切换；简答在核对点未全部勾选时不能保存自核。

## 边界

图谱中的层级和跨分支关系均保留在星球草稿并供预览；当前普通课程知识点数据结构只保存父子层级，游客确认时将层级写入普通课程。定制图地址进行 HTTPS 和公开主机名的语法检查，不将它描述为 DNS 解析安全保证。检索依据是否充分、具体题目是否正确、真实模型能否完成图像与内容重生，需要独立的服务端真实调用和人工内容审阅证据。

## 相似碎片与分阶段提示验证

本轮在每道练习增加“相似碎片搜索”，请求两道同题型新题并保留原题、答案与基础区域进度；预览沿用更新后的签名，游客沿用相同预览重生接口。新题的局部 `practiceResearch` 独立校验，不能与星球全局同名来源编号互换。后续用户主动改写题型允许改变母题或补题，不强制连带改写其他练习；生成两道时的同题型约束由服务端检查。

学习导航保留故事、讲述、知识图谱及来源。进入探索练习后隐藏这些资料，题卡不直接显示外链；补题来源可回到学习导航的“相似碎片资料”查看。题卡内“问星芽”使用既有真实聊天接口，只发送主题、可见题干与选项、区域课文和用户提问，不发送参考答案、评分字段、解析或核对点。提示要求引导思考；这项请求约束不等同于模型绝不会直接给出答案的保证。
