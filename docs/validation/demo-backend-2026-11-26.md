# 演示升级后端验证

日期：2026-11-26。范围为当前账号课程、导入资料、AI 资料检索与学习规划调用链；本代理没有执行部署或直接操作生产数据库；主线程发布后，已获授权通过 API 创建隔离验收账号验证线上闭环，没有修改既有用户，也没有把题目设为人工已审核。

## 修复结果

此前，直接导入课程资料后，学习规划只查知识点和笔记，因此仅有导入资料的课程会被判为没有依据。现在链路为：导入资料 → 读取本账户、未归档课程的最新有效版本 → 按问题检索片段 → 记录版本与片段 ID → 规划结果校验 → 用户确认后创建任务。全局助手的资料检索也能读取匹配的导入片段。

`currentMaterials.ts` 先确定各资料最新版本，再过滤删除标记与解析状态，避免退回旧版本。生成过程中或确认前，若所引用资料被替换或删除，计划会被拒绝；错误提示要求重新生成。确认只检查实际引用资料，因此后来新增大量无关资料不会把有效引用误判为失效。确认写入与同账号其他任务写入共用用户锁，重复或同时确认只创建一次任务。接口新增兼容错误码 `PLAN_STALE`。

主要入口为 `AgentService.prepare / tool / execute / confirm`、`retrieve` 和 `currentMaterials`。不新增数据库表，不改变客户端请求字段。规划最多准备 12 个导入片段、最终检索最多 8 条来源；全局助手最多加入 3 个匹配片段。广域发现考虑最近变化的 40 份资料，不能据此声称已建立全库语义索引。

## 验证

执行 `npm test`，86 项通过，0 项失败；该命令同时执行 TypeScript 编译。测试使用独立临时 SQLite，新增 3 项回归覆盖：

- 仅导入资料的课程可以产生有依据的模拟计划；陌生账号资料不进入上下文；两次并发确认只建立一次任务；生成后新增 41 份无关资料不影响有效确认。
- 替换、删除资料，以及生成过程中资料发生变化，均阻止使用旧引用创建任务。
- 全局助手只读取本账户最新有效资料，排除旧版本、已删除、归档及其他账户内容。

自动回归使用模拟模型输出，只验证后端行为。已有真实 HTTP 测试同时覆盖注册认证、笔记版本冲突、课程归属、任务完成幂等、资料导入、PDF 文字解析、排程确认和取消恢复等行为。它们不是浏览器、手机或真实模型效果的证据。

脱敏机器记录见 `docs/validation/demo-backend-2026-11-26.json`。完整本机测试日志位于 `.cache/full-demo-20261126/backend-tests-after-content.log`。
