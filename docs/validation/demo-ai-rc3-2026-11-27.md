## 问题与实现

原华为工作流 API 已真实返回计划，但独立模型节点缺少原账号证据。为验证模型本身及产品后续操作，当前部署接入妙搭官方公共模型能力。网页和 Android 发送请求到共享 API，模板中的 `NativeAiService` 再调用原生文本生成或结构生成插件；服务端验证返回结构及来源，再把结果交给用户预览。长请求使用独立任务编号轮询，不拿固定样例替代失败。

主要代码入口为 `apps/server/src/ai/native.ts` 与 `deploy/miaoda/server/modules/gateway/native-ai.service.ts`，能力定义在 `deploy/miaoda/server/capabilities`。本轮规划配置为 `PLANNING_PROVIDER=auto`，实际提供方为 Miaoda，通用对话模型标识为 `miaoda-chat`。这个标识不证明底层供应商或模型商品名称，材料中不猜测其为华为、DeepSeek 或其他具体模型。

知识星图使用本地嵌入的 AntV X6 3.1.8 与 Dagre 3.1.4：课灵提供节点和关系，代码交给绘图引擎排布与交互。Web iframe 和 Android WebView 加载同一份资源。布局保存有版本检查，冲突时保留调整并提示重新读取。图谱引擎不承担教材正确性判断。

## 演示顺序与复现

1. 打开网页或 Android，登录账号或选择游客体验。阅读启航故事，输入学科、学习基础与目标，生成预览后确认。游客刷新或退出会清空，跨端接续需使用同一账号。
2. 打开学习区域，读讲解、提交答案、查看解析，用自己的话保存航行日志，再添加下一次任务。通用学科提供短讲解与单选练习；二叉树是另外主动选择的专属规则示例。
3. 在课程中导入自己的短资料，预览将发送的材料，再使用公共模型提问。核对回答后保存为笔记，退出页面并重新打开，检查原问题与来源仍在。
4. 在 AI 学习计划中选择资料、目标和时间预算，生成后核对来源、日期、时长，再确认加入任务。重新确认一次，应显示已有任务而不重复创建。任务状态变化后可请求复盘，复盘建议仍需确认。
5. 打开有多个知识点和关系的星图，自动排布后拖动一个节点并保存。同一账号在另一端打开，再修改保存，回到首端重新读取，核对布局接续。

模型服务或网络失败时保留输入、展示错误，可稍后重试；不能据此显示“已生成”或“已保存”。并行密集轮询可能触发账号请求限制，演示应按步骤操作。默认向量模型未配置，当前检索不能称为已经验证的向量语义检索。17厂商个人 Key 目录也不代表17家已全部实测。
