# 个人空间与成就规则

从“我的”进入个人形象、星图家园、远航成就或学习轨迹。十种头像可直接选择，头像框、称号牌和家具随着学习记录解锁。选好后保存，登录同一账号可以重新读取；游客记录只在当前会话内保留。

星球生成预览尚未创建课程，因此不会提前获得“第一颗星球”成就。达到条件后，装饰可以在对应页面使用；家园提供十个位置，每件家具只陈列一次。展示截图中的两件家具来自真实完成的一项任务和保存的一篇笔记。

计时器按实际经过的时间记录，支持暂停和继续。没有计时就直接完成任务时，计入 0 分钟；预计任务时长只是安排预算。重复提交同一次完成不会重复累加。100 小时对应累计记录 6000 分钟，当前验收账号只实际记录了 1 分钟，没有人为写入长期成就。

小日历位于首页日常打卡旁边，手机也采用并排布局。点日期可回看当天已记录的分钟数、完成任务和是否打卡；日期按北京时间归档。缺少日期的历史累计时长不会被分摊成虚构的日历记录。记录时长并不能证明真人一直专注，成就也不代表已经掌握某门学科。

## 实现对应

共享定义位于 `packages/shared/src/journey-catalog.json`，包含上述十项条件与所有图片格位。网页与 Android 读取同一份定义。账号的实际记录由 `apps/server/src/services/journey.ts` 汇总，`/api/journey/profile` 提供装备保存和读取，`/api/journey/calendar` 提供月份记录。未解锁的装饰不能通过直接调用接口装备，冲突保存要求重新读取，两个账号的状态相互隔离。

Web 的入口和交互位于 `apps/web/src/pages/Profile/JourneyStudio.tsx`，Android 位于 `apps/android/app/src/main/java/com/keling/app/journey/JourneyScreen.kt`。四幕故事分别由两端 StoryDialog 组件呈现；桌面原画与 PPT 座舱同源，手机使用纵向适配原画。十种头像、十款框、十块牌与十件家具的原稿和提示词可在 `assets/stellar/journey-art-provenance.json` 追溯。

自动验证和真实操作的范围分别记录于[服务端验收](../validation/journey-backend-2026-11-27.md)、[发布验收](../validation/journey-release-2026-11-27.md)和[材料证据](../validation/journey-materials-2026-11-27.json)。实体手机与内容审阅在[最后人工事项](../validation/manual-followups-2026-11-27.md)中单独列出。
