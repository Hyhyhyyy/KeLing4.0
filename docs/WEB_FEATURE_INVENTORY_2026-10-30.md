## 1. 阅读口径与运行边界

- **已接通**：页面有实际可达入口，按钮或表单调用了对应逻辑，涉及保存时可追到服务端处理。这是源码审查结论，不能替代当前部署环境下的端到端实测。
- **有条件可用**：还需要账号、服务地址、数据库、管理员模型配置，或用户自己有效的模型密钥。本次没有调用真实收费模型，不声称各厂商推理、模型发现或华为 AgentArts 已全部实测成功。
- **展示/示例**：图片、介绍文字、固定教学答案、推导出的统计，不当作独立业务能力或真实 AI 结果。
- **未闭环**：有控件但不能保存、保存字段不被后端接收、只有 API 没有页面入口，均明确列出。
- 本次只读检查路由、页面、服务调用和后端；没有启动浏览器、重新运行测试、修改功能代码或图像。移动端的实际功能应另据 Kotlin 代码核实，不以网页中的宣传文字代替。

## 3. 注册、登录、账号与首页

### 注册与登录

- 邮箱、密码登录；姓名、邮箱、密码及重复密码注册；注册校验两次密码相同，密码长度 10–128 位。
- 后端规范化邮箱、哈希密码，签发 7 天 JWT；前端保存 token，登录后进入首页并读取账号数据。
- 读取当前账号失败可重试；退出清除账号数据缓存和登录凭据。
- 没有已接入的邮箱验证码、邮箱验证、忘记密码、修改密码、第三方 OAuth 登录、注销账号、家庭/班级/组织账号管理界面。不能把邮箱输入控件称作邮箱身份验证。

接口：`POST /api/auth/register`、`POST /api/auth/login`、`GET /api/auth/me`。

源码：`pages/Auth/Login.tsx`、`pages/Auth/Register.tsx`（均位于 `apps/web/src`）；`apps/server/src/controllers/auth.ts`、`middleware/auth.ts`、`config/security.ts`。

### 首页与签到

- 显示账号昵称、共享课程数、未完成任务数、笔记数、累计学习分钟。
- 显示最多 3 项待完成/进行中任务，点击进入任务页；显示最多 6 门课程并可打开详情。
- AI、课程、笔记、任务、智能编排、视觉图鉴都是真实导航入口。
- 查询今日签到状态后才能签到；领取当日能量/结晶并重新读取用户资料；跨端已签到会提示同步结果。
- 服务端按 UTC+8 的日期记录签到，用事务与每日唯一记录避免重复领取。连续签到按昨日是否签到延续，奖励按 7 日周期循环。这里的“连续学习”文案实际依据签到天数，不是每天存在专注记录。
- 首页任务卡不直接开始/完成任务；装饰性的空间场景、吉祥物不是游戏关卡或可操控角色。

接口：`GET /api/checkin/status`、`POST /api/checkin`，以及账号列表接口。

源码：`apps/web/src/pages/Home/StellarHome.tsx`；`apps/server/src/controllers/checkin.ts`、`services/checkin.ts`。

## 4. 课程与知识点

### 课程列表、创建与详情

- 列出自己的课程；创建时可填写名称、课程代码、教师、地点和主题颜色。课程卡可进入详情，可确认删除。
- 详情展示课程基本信息、已有课程掌握度、累计学习分钟、知识点数量、学习次数。
- 详情支持编辑名称、代码、教师、地点；确认删除课程。
- 可在详情通过文本提示框输入名称，新增一个知识点。新增后重新加载知识点列表；此入口没有知识点正文或父节点编辑表单。
- “问 AI”带该课程引用进入 AI 资料预览；点击发送前不调用模型。
- “创建任务”只是跳转任务页，不预填课程，不直接创建任务。
- 课程掌握度是后端已有字段的展示。网页没有明确的课程掌握度维护入口，也没有根据节点掌握度自动汇总课程掌握度的完整调用链。
- 网页没有课表日历、考试日程管理、学分/学期编辑、课程文件附件上传界面；后端字段存在不等于网页已实现。

**已发现的未闭环项：**创建课程表单有星球样式选择，但 `controllers/courses.ts` 的 `createCourse` 没有接收 `planetStyleIndex`。当前不能宣称该选择已保存并跨端同步。

接口：`GET/POST /api/courses`、`GET/PUT/DELETE /api/courses/:id`；`GET/POST /api/knowledge/:courseId/nodes`。

源码：`apps/web/src/pages/Greenhouse/Greenhouse.tsx`、`CourseDetail.tsx`；`apps/server/src/controllers/courses.ts`、`controllers/knowledge.ts`。

### 知识图谱

- 按课程读取知识点与父节点 ID，在画布上计算层级布局，用连线和节点颜色显示关系及掌握度。
- 已接入缩放按钮、鼠标滚轮缩放、鼠标拖动画布和初始自适应视图。移动的是视角，不是把节点拖到新位置并保存；未看到触摸手势缩放/拖动的完整实现。
- 点击已有节点可打开编辑框；名称、描述、掌握度可以通过更新接口保存；已有节点可确认删除。
- 图谱视角、缩放比例是当前组件状态，不跨设备同步。

**不能当作完整功能的部分：**

1. 图谱页“添加知识点”打开编辑框时 `editingNode` 为 `null`；输入回调仅在旧值非空时更新，而保存按钮要求 `editingNode.name` 非空。因此该新增弹窗目前无法完成新增。可用替代入口是课程详情的名称提示框，以及智能编排页的资料表单。
2. 已有节点的“父节点”和“难度”控件虽然可显示/选择，但 `updateNode` 只接收名称、描述、掌握度、解锁与位置字段，不处理 `parentIds` 和 `difficulty`，因此不能算作可保存的编辑能力。
3. 空状态“和 AI 聊聊，让它帮你创建知识图谱”只跳 `/ai`；普通 AI 回答不会自动写入知识点或生成图谱。批量创建 API 也没有连接网页上传/导入界面。
4. 网页没有明确的知识点解锁操作；编辑节点掌握度不等于 `isUnlocked=true`，也不会自动推进课程掌握度。不能宣称“掌握知识点 → 解锁成就 → 提高课程掌握度”已闭环。

接口：`GET /api/knowledge/:courseId/nodes`、`PUT/DELETE /api/knowledge/node/:id`。存在但未接网页批量导入界面：`POST /api/knowledge/:courseId/nodes/batch`。

源码：`apps/web/src/pages/KnowledgeGraph/KnowledgeGraph.tsx`；`apps/server/src/controllers/knowledge.ts`、`routes/knowledge.ts`。

## 5. 任务与网页专注

- 新建任务：标题、五种类型、可选关联课程、预计分钟。奖励由服务端按类型计算，前端展示预览。
- 列表可按全部、待完成、进行中、已完成过滤；显示待完成、进行中、今日完成数量。
- 待完成任务可开始、删除；开始后服务端状态变为进行中，本页启动基于 `performance.now()` 的正向计时。
- 已进行中任务可完成。完成事务只奖励一次，同时更新用户学习分钟、能量、结晶、经验、等级，以及关联课程学习分钟/次数和任务成就进度。
- 当前计时任务完成时提交已计时的整分钟；其他任务完成时不提供当前计时值，后端可能采用任务已记录分钟或预计分钟。
- 任务卡可带任务资料进入 AI；当前有活动计时时会禁用该入口并说明原因，避免切页丢失计时。

**当前计时边界：**

- 账号任务页是正向计时，不是带休息周期的完整番茄工作法。未接入结束闹铃、系统通知、网页后台唤醒或屏幕常亮。
- 页面只有一个当前计时任务；切换会要求确认。停止清空本地计时，不把已计时分钟保存为独立专注记录，也不把任务状态改回待完成。
- 离开/刷新任务页会丢本地计时；服务器的进行中状态仍在。重开后没有完整的该任务暂停/继续按钮链路，只能按现有完成入口提交。
- 无计时直接完成时，报告中的实际分钟可能来源于预计时长，不能称作精确自动追踪。
- 新建表单没有可编辑描述、优先级、截止日期控件；没有已接入的编辑任务、放弃/恢复任务、日历拖排、提醒设置界面。编排生成任务能带计划日期，但普通任务页面没有完整日历安排功能。

接口：`GET/POST /api/tasks`、`PUT/DELETE /api/tasks/:id`、`POST /api/tasks/:id/complete`。

源码：`apps/web/src/pages/Tasks/Tasks.tsx`；`apps/server/src/controllers/tasks.ts`、`services/taskCompletion.ts`。

## 6. 共享笔记与资料导入/导出

- 列出自己的共享笔记，可按标题/正文在已加载列表中搜索；新建、选择、编辑标题与正文、保存、删除。
- 手工编辑的正文是文本/Markdown 源码，不是富文本可视化编辑器。
- 新建/切换笔记时，非空未保存草稿有放弃确认；保存过程中禁用编辑。此确认不是全站路由离开保护，刷新或直接跳其他模块仍可能丢草稿。
- 更新携带 `expectedUpdatedAt`，服务端用版本条件避免静默覆盖另一端较新内容。冲突时保留当前草稿，提示先导出，再重新载入最新版本；没有自动合并或多人实时协作。
- 导入 `.md` 或 `.txt`：单文件读取本地文本，文件大小上限 200000 字节、正文上限 50000 字符，导入成为可编辑草稿，点击保存后才上传共享数据库。
- 导出当前草稿为 Markdown 文件，可在尚未保存时保全本地编辑。
- 只有已保存且未继续改动的笔记可以“带资料问 AI”；新笔记和脏草稿禁用该入口，避免把旧保存内容冒充当前草稿。
- AI 共享回答、账号自带 Key 回答可以通过明确的保存操作成为共享笔记；不会自动把所有问答写入笔记。

**不包含：**PDF/Word/图片/扫描件导入、OCR、语音转写、网页抓取、多文件知识库、文件自动拆段入库、从导入文档自动建立知识图谱、云盘附件管理。笔记标签/关联节点等服务端字段不等于网页已有完整管理界面。

接口：`GET/POST /api/notes`、`PUT/DELETE /api/notes/:id`。

源码：`apps/web/src/pages/Notes/SharedNotebook.tsx`；`apps/server/src/controllers/notes.ts`、`routes/notes.ts`。

## 7. AI 助手：共享学习会话

入口：`/ai` 的“共享学习会话”模式。依赖登录、服务端数据库和至少一个管理员启用的聊天模型。

### 用户可操作内容

- 选择服务商、管理员允许的聊天模型及六种学习方式：概念讲解、学习规划、薄弱诊断、逐题练习、复习回顾、自由问答。
- 可主动查询服务端模型目录；查询结果不自动启用，仍需管理员配置允许使用的模型列表。
- 新建会话草稿、输入问题、点击发送才创建/提交会话；单条问题最多 6000 字符，支持 Ctrl/Command+Enter。
- 列出最近会话并按标题搜索，打开历史、删除共享会话、导出 Markdown；删除会话保留已经单独存下的笔记。
- 活动会话轮询刷新，页面重新聚焦也读取状态；运行中可停止生成。失败可把原问题取回编辑，连接失败可重新读取服务端状态。
- 每轮显示用户问题、模型回答或运行/失败状态，可展开当轮资料文本快照、来源、版本/截断说明及模型报告用量。历史缺少版本的记录明确说明版本未知。
- 成功回答可点击“保存到共享笔记”，保存真实回答与引用资料，供同账号两端读取。

### 资料怎样进入模型

1. **明确选定资源**：课程、任务或已保存笔记的入口只传资源引用，在 AI 页向服务器获取自己的资料预览。可检查真实内容、截断提示，编辑问题、刷新或移除资料；预览失败不发送。发送时再次校验版本指纹，资料变化返回 409，保留问题并要求刷新预览。
2. **按需检索**：新会话可开启资料检索，默认关闭。关键词检索按当前问题匹配；向量检索另选管理员启用的嵌入模型。嵌入模型把文本变为数字向量用于相似度比较，不直接生成聊天回答。
3. 检索候选是最近 24 个知识点和 12 篇笔记，每项取至多 1000 字符，最终最多 6 项；向量在本次请求中计算。不是覆盖全部资料的长期向量数据库，也不能保证找到旧资料。
4. 显式资源预览与历史轮次资料均有可追溯文本。临时资源引用是账号绑定的内存状态，避免全文放 URL；切换账号、开启新会话或切换历史时清理。

### 模型与能力边界

- Ollama 指服务器可访问的本地服务，不是浏览器自动连接用户电脑的模型。
- 六种学习方式是对话提示模式。“薄弱诊断/逐题练习”没有独立的考试引擎、客观能力评分或长期自适应测评闭环；“学习规划”聊天模式也不会自动生成任务，写入任务应使用独立编排模块并确认。

## 9. 智能编排：资料到计划再到任务

入口：`/agent`。需要账号、课程、可用资料，以及部署管理员配置的华为 AgentArts 或 DeepSeek 规划服务；未配置会显示不可用，不能通过前端外观证明已连接华为服务。

- 可选课程，填写目标（最多 1200 字符）、从今天到未来 90 天内的考试日期、每日 10–480 分钟、计划/复盘模式。
- 页内有“创建课程”与“添加课程资料”表单；后者实际新建一个知识点，标题最多 180、正文最多 1800 字符。它不是文件上传器。
- 点击开始后创建持久运行，显示真实阶段事件、状态、结果/失败信息；可查看最近运行历史、重新读取和查看已有运行。运行中定时查询，可离开后回来检查。
- 后端选取该课程知识点与相关笔记，按任务限定的检索工具取得资料；返回计划需经过日期、时长容量、引用来源校验。
- 成功后显示计划摘要、每天任务、预计分钟和引用来源；只有用户点击确认，才在事务内创建关联该课程的共享任务。重复确认不重复创建。
- 确认生成的任务可到任务页执行，任务完成进入学习统计；这是当前实际接通的“资料 → 计划 → 人确认 → 任务”链路。

边界：

- 不是跨应用自主智能体；不会自动发消息、操作系统、替用户提交计划或修改任意数据。
- 资料候选有界：最多 80 个课程节点，从最近 100 篇笔记中筛选最多 20 篇相关笔记；正文摘要最多 1800 字符，检索最多返回 8 项。不是任意个人全量知识库。
- 相关笔记以关联节点或标题包含课程名等规则选取，不是用户手工连接资料库的完整管理 UI。
- 编排记录保存来源 ID/标题与事件、结果；不同于普通 AI 轮次的完整文本版本快照，不能保证旧计划永久重现当时每段资料全文。
- 现有页面不能逐项编辑模型给出的计划再确认，没有日历拖动、删除运行历史、显式取消运行按钮；可以修改目标重新运行。运行有失败/过期状态，不能承诺任意时长任务后台可靠执行。
- 复盘模式是基于资料和已有任务的规划/复盘结果，不是独立的学习效果因果评估。

接口：`GET /api/agent/status`、`GET /api/agent/runs`、`GET /api/agent/runs/:id`、`POST /api/agent/runs/start`、`POST /api/agent/runs/:id/confirm`；服务端受限工具入口 `/api/agent/tools/search`。

源码：`apps/web/src/pages/Agent/Agent.tsx`；`apps/server/src/agentarts/{routes,service,deepseek,runtime,contract}.ts`。
