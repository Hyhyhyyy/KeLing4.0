# RC3 标题美术与布局记录

日期：2026-11-25。候选版本 4.0.5-defense-rc3 / Android versionCode 23，基于 RC2 提交 `130c6f5ab50de9afb04dbc281259e99653a3ef50`。

## 绘制与接入

使用内置 image_gen，以现有星芽两张角色图为参考，新绘一张透明 3×3 图集。九格对应欢迎、AI 导师、远航、课程、笔记、专注、报告、成就、设置；服装、面部、叶芽及配色保持同一角色。没有使用 emoji 图片或表情包作为新装饰。

原始 PNG 保存在 `assets/stellar/sources/title_mascots.png`，运行图集为 `assets/stellar/title_mascots.webp`；尺寸 1254×1254，每格 418×418，WebP 采用无损编码，像素与透明通道与原 PNG 完全一致。[完整提示词及创作来源](../../assets/stellar/title-mascots-provenance.json)可追溯。

Web 的 `ModuleTitle.tsx` / `ModuleTitle.css` 与 Android 的 `StellarHeading.kt` 为标题统一分配角色。主标题旁显示对应星芽；次级标题使用原创 SVG / Canvas 线稿（星点、轨道、书本、指南针等）。图片只作装饰，不重复加入读屏标题。动态内容仍可换行，已精简的说明文字没有因装饰重新增加。

Web 角色在桌面为 72px，窄屏为 52/44px，次级线稿 20/18px。Android 角色 52/44dp、线稿 20dp；图片由统一共享资源生成到 APK，不另维护第二套运行图。
