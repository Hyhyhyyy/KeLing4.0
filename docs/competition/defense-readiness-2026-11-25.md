## 本轮程序修复

1. 华为工作流返回等待输入时，不再把结束事件当成计划成功；同时存在展示文字和 `user_fields.plan` 时优先读取结构化计划。修复及回归在 `apps/server/src/agentarts/runtime.ts` 与对应测试。
2. Android 对当前应用的 feishu.link / feishuapp.com 两个精确 HTTPS 地址处理同一账号服务及平台 CSRF 校验，避免新版入口 POST 失败。
3. Android 本地数据保存显式保留默认值，避免创建后立即保存的对象漏写创建时间、重新读取时改变时间戳。
   同时移除系统重复标题栏，导航栏资源保持 Android 8.0 兼容。
4. 提供 `demo.bat` / `npm run demo`，每次启动建立独立 SQLite 演示库，同源提供已构建网页和真实应用 API。这个入口只监听本机，模型密钥不会从开发环境继承，外部模型请求关闭。原有环境和生产数据库不受影响。

华为链路的直观理解是“先读资料、生成草案、再由人确认写任务”。具体入口为 `/api/agent/runs/start` → `AgentService.prepare/execute` → 当前账号课程检索 → Runtime → `validatePlan` → 待确认草案；`confirm` 通过事务创建任务，重复确认不重复增加。复盘读取任务完成状态和实际时长。接口返回 HTTP 200 可能只是运行记录读取成功，必须查看运行状态是否为 SUCCEEDED / CONFIRMED。

## 本机排练方法

在主工程双击 `demo.bat`，或运行 `npm run demo`。首次需要安装 Node.js 22.13+ 及 `npm ci` 依赖；依赖齐全后无需连接生产库。终端显示就绪后打开 `http://127.0.0.1:4173`。每次启动使用新数据库，旧演示库留在 `.cache/defense-demo/session-*`；新启动后需重新注册本机演示账号，不能用线上账号密码替代。游客内容刷新即清空，账号模式的数据保存在本次演示库。

重启、测试或重新构建前先在原演示终端 Ctrl+C 停止服务。Windows 正在运行的 SQLite 客户端会占用引擎 DLL，同时重建会报 EPERM；本轮停止演示进程后重跑 `npm run test:demo` 已通过。执行结束后已停止本轮临时演示进程。

推荐自查操作：进入游客空间 → 远航 → 选择示例课程 → 教星芽/二叉树操作 → 提交实际答案 → 查看反馈 → 写下一步。另用本机账号创建课程、笔记和任务，再退出并重新登录核对保存。前者验证学习过程，后者验证真实数据保存；两者均不证明云端 AI 或跨设备同步。

现场以已验证的功能演示，固定规则提示明确标为规则，不用伪造 AI 输出替代失败的服务。运行原提交视频不等于当前程序经过验收。
