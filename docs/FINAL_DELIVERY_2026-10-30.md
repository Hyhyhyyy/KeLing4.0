## 问题、改动与学习流程

原先的问题是资料与提问分离、试用要经过账号入口、模型只能由管理员配置，而且多个模块复用了少量场景。本次把实际可操作的学习路径接起来：选择课程或已保存笔记/任务 → 核对摘录 → 编辑问题 → 明确发送 → 核对回答 → 保存笔记或确认任务 → 计时与手动完成。

账号模式保留云端课程、笔记、任务、头像和会话。网页侧重长资料整理与模型选择；Kotlin 侧重随身查看、纵向资料卡、任务与专注。两端指向同一 API，但未提交草稿、计时状态与临时 Key 不声称跨设备同步。

免登录试用是独立的内存工作区：可以读示例课程、标记理解、编辑笔记、添加或完成任务、进行真实时间的专注计时。固定教学回答有“非模型生成”标识，不会冒充对当前问题的回答。用户明确操作后，回答才转为内存笔记或任务草稿。页面退出/刷新或 Android 页面销毁后清空，不自动迁入共享账号；主动复制到系统剪贴板的内容由系统管理。

Android 中未接入通知、提醒、声音和震动的五个开关已禁用并说明，避免用可切换的外观冒充真实功能。当前无 Key 时仍能完成阅读、笔记、任务和专注流程；真实 AI 生成需要有效模型授权。

## 资料问答怎样保证可核对

“上下文”指本次发给模型的辅助资料；“指纹”是根据资料内容和版本计算的校验值，不是权限凭据。

1. Web 的 `assistantLaunch.ts` 与 Android 的内存入口只传资源类型、ID 和通用问题，不在 URL 中放正文。
2. `POST /api/ai/context-preview` 由 `apps/server/src/ai/context.ts` 按当前账号查询资源，返回准确摘录、版本、截断说明和指纹。读取预览不调用模型，也不创建云会话。
3. 用户发送时，`service.ts` 再次检查归属与指纹。资料改变返回 409 `CONTEXT_CHANGED`，缺失/不属于用户的资源统一返回 404；客户端保留问题，要求刷新或移除资料。
4. 请求接受后保存当时的来源快照，再进入模型调用。运行、成功、失败、取消均保留已接受的来源。普通检索路径也在调用前保存快照。
5. 重试使用请求编号识别同一次提交。加入上下文的请求使用独立标记和结构化编码计算摘要，避免普通文本后缀与上下文发生身份混淆；字段顺序变化不制造新请求。
6. 用户明确保存回答时，笔记包含回答及来源快照，不偷偷替换成后来修改的资料。

显式资料只替代本次全局检索，不清空同一账号会话中已有的成功历史。笔记最多 6000 字符；任务描述最多 4000 字符并附状态与预计时间；课程最多最近 6 个知识点、每个 1000 字符。普通检索仍受最近 24 个知识点和 12 篇笔记的窗口限制，没有全库向量数据库。详细字段与失败语义见 [契约](AI_CONTEXT_CONTRACT.md)。

## 用户 Key 与实时模型目录

API Key 是用户在模型服务商处的访问凭据。双端在 AI、设置和试用中均提供明显入口，目录预设 17 家云服务。管理员还可配置一个自建兼容服务；共享账号会话保留既有 14 类管理员配置入口，两类目录用途不同。

- 格式候选仅在本地判断。Anthropic、OpenAI 部分前缀和 Gemini 前缀可以给出候选；普通 `sk-` 或 JWT 不能可靠判断归属，须由用户选择。候选不是有效性验证，不向多个厂商广播 Key。
- `GET /api/model-access/catalog` 读取服务入口；用户点击后，`POST /discover` 仅把 Key 交给所选厂商的官方 HTTPS 地址。客户端不能提交任意远程地址，重定向不被自动跟随。
- 模型列表来自当次厂商响应并附获取时间，最多读取 5 页；厂商可能不提供完整目录或能力字段。目录不等于全部授权模型，能力未知时不伪造标签。仅向量模型不能直接用于聊天，可手填已开通的聊天模型 ID。
- 部分服务需要官方地域/工作区地址。华为大陆 MaaS 的目录路径不作为已支持能力宣称，可手填模型；华为香港 v2 目录有对应实现。所有真实厂商可用性仍未实测。
- `POST /complete` 只提交本次问题和所选摘录，不携带账号令牌、不创建共享会话。问题最多 4000 字符，资料最多 3 条、每条 2000 字符。Key 不进入 URL、响应、应用日志或数据库；离开配置界面、切换账号、退出或清空后不恢复。
- 临时问答并不意味着模型商没有日志或不计费。发送前提示内容处理与费用；取消客户端等待不保证模型商停止已经收到的请求。

公共管理员试用 AI 默认关闭，即使共享账号配置了 Key，也须单独显式启用。临时 Key 与公共试用接口均设单实例的内存请求限额；这不是跨实例、持久化的统一配额。没有自动重试付费调用或默认把账号资料发送给第三方的流程。

## 独立视觉资源与动态边界

本版共 44 张规范 PNG，其中 29 张是完整场景或入口原画。本轮新增 24 张独立构图，分别对应规划、报告、个人空间、成就、设置、图谱、登录、注册、课程详情和介绍等位置；不是把同一张图片放大缩小后当作新图。相同模块跨端可共享图，品牌角色保持一致。

规范来源为 `assets/stellar`，Web 和 Android 使用相同字节的副本。`prompts-module-scenes.json` 保留生成提示词和源文件位置。网页用宽幅与分栏，手机用短幅或保持比例横幅；文字、输入框和按钮均为真实控件。界面保留加载、点击和状态反馈，装饰遵循系统减少动态效果的偏好；未完成所有设备的动态、对比度和读屏验收。

保留完整 PNG 带来真实体积成本：APK 约 146.5 MiB。没有以原画数量代替加载性能、流量、内存或低端设备性能证据。
