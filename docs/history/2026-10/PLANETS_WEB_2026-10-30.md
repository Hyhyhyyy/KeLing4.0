# 3.2.5：报告按钮与十款知识星球

> 历史记录（2026 年 10 月）。保留当时版本、操作和验证结论；当前入口与运行方式见[文档索引](../../README.md)。

## 问题与修复

课程详情的全局 `.action-btn` 曾将报告页同名按钮约束为 40×40。报告底部现使用独立样式，宽高随内容展开，文字允许换行，点击高度至少 48px；课程页面样式限制在所属页面内。

新增十张独立透明像素原画，存放于 `assets/stellar/planet_01.png` 至 `planet_10.png`。使用内置 image_gen 分别生成，没有将同一图缩放后充当不同图；提示词与生成源文件名完整保存在 `assets/stellar/prompts-planets.json`。两端通过同步脚本消费一致资源，目前共享资源总数为 54。

`planetCatalog.ts` 定义 0–9 的统一名称与路径。`CoursePlanet` 用于首页、课程列表与详情；新建和编辑课程都可选择星球。`planetStyleIndex` 沿用现有课程字段，服务端创建／更新现在校验并保存该字段。此前前端虽然发送编号，服务端却没有保存。游客路径使用同样的编号，只保存在本次内存。

外观修改不改变课程知识点、掌握度、学习时间或用户奖励。旧数据不删除；新目录中的非法索引在展示层回退。Android 旧本机空间仍能读取历史 10–25 编号，新增选择统一为 0–9。

## 验证

- 服务端 50/50 测试通过，新增真实临时 SQLite HTTP 用例覆盖十款保存、读取、外观修改保护、越界和越权。
- Web 游客 24/24 测试通过，额外核对十款内存选择与资料隔离；Web/Server 构建通过。
- Web ESLint：0 错误、34 警告。54 张共享图片的字节、尺寸和校验值一致。
- Android：55/55 测试通过，构建通过，lint 0 错误、97 警告；详细 APK 校验见 `PLANETS_ANDROID_2026-10-30.md`。

本轮浏览器自动化无法可靠读取页面，电脑操作工具随后因无法确认当前浏览器地址而停止。**320/390px、200% 字号的本轮实际视觉检查未完成**；不能将 CSS 审查与构建测试称作视觉验收。Android 真机、真实双设备同步及真实模型调用仍未实测。

## 复现

进入游客知识星球页面，新建课程并选择任意星球；在详情更换外观后返回首页与课程列表，检查图案一致和学习数值保持。进入课程详情再返回报告页，核对底部两个按钮文字完整、可换行和可点击。登录模式以同一账号在另一端重新读取课程；游客退出或刷新后不恢复本次选择。
