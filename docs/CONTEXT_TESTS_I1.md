# I1 上下文问答服务端测试说明

初始日期：2026-10-29；最终核验：2026-10-30。契约依据：[AI_CONTEXT_CONTRACT.md](./AI_CONTEXT_CONTRACT.md)。测试入口：`apps/server/tests/context.test.cjs`。

## 检验对象与执行状态

这组测试检验“用户预览的资料，是否就是提交后保存并用于生成的资料”。它覆盖真实数据库读写、服务层状态变化以及 HTTP 路由；生成响应由测试函数注入，只检验调用参数和生命周期，不代表真实模型效果、在线可用性或答案质量已经验收。

最终状态：主线统一运行服务端测试 44/44 项通过，0 失败、0 跳过，日志为 `.cache/final-server-tests.log`。本说明覆盖的 8 组显式上下文测试和 1 组普通关键词检索快照测试均通过；其中包含修复后的散列冲突、字段顺序重试回归。第一次 37/37 的记录保留于 `.cache/context-i1-server-tests.log`，最终结论依据补充后的 44 项复测。

## 覆盖内容

| 检验对象 | 可观察结果 |
| --- | --- |
| 引用输入 | 只接受课程、笔记、任务及资源 ID；拒绝用户伪造的 `userId`、正文、URL 类型和无效版本。 |
| 预览归属与版本 | 不配置模型仍可读取三个类型的预览；返回来源时间与 SHA256 指纹；外人资源、缺失资源和归档课程均返回 404。 |
| 资料范围与长度 | 笔记最多 6000 字符，任务描述最多 4000 字符，课程仅最近 6 个知识点、每个最多 1000 字符；排除同账户其他课程及其他账户资料；分别验证文本截断与选择数量上限提示。 |
| 提交重新校验 | 即使持有别人的正确指纹，提交也返回 404；缺失和归档资源同样拒绝，均不创建 turn 或调用生成器。 |
| 版本改变 | 预览后修改笔记，提交旧指纹返回 409 `CONTEXT_CHANGED`；生成器调用数、后台任务数、turn 数均为 0。 |
| 幂等和范围选择 | 显式上下文不触发全局检索；相同请求号重发返回原 turn，模型只调用 1 次；字段顺序变化不改变请求身份；替换或移除 context 的同号请求返回冲突，普通消息的 JSON 后缀不能伪装结构化上下文。接受后资料变化不改变原请求快照。 |
| 快照与保存笔记 | RUNNING、SUCCEEDED、FAILED、CANCELLED 均保留接受时来源；失败和取消不可保存为回答笔记；成功保存保留回答、来源标题、正文和版本时间，重复保存得到同一笔记。 |
| 普通关键词检索快照 | 检索来源带 `updatedAt` 和 `truncated`；调用生成器前保存快照，注入生成失败后仍能读取对应来源。 |
| HTTP 保护 | 未登录返回 401；合法预览设置 `Cache-Control: no-store`；外人资源和不存在资源的 404 正文相同；额外字段和不支持类型返回 400。 |

## 复现与隔离

由主线在项目根目录运行既有命令 `npm test`。其中 `scripts/test-server.cjs` 创建系统临时目录内的独立 SQLite 数据库、初始化表结构，再运行所有服务端测试。此文件刻意拒绝在非 `NODE_ENV=test` 或不属于该临时数据库路径的环境执行，避免误写开发或部署数据库。

夹具使用随机用户 ID 和合成内容。每组结束清理自己的 AI 会话、turn 和用户数据；异步生成任务先释放并等待结束，再删除夹具。配置模型的测试仅在本测试进程内临时设置 `AI_CUSTOM_*`，随后还原；Node 默认按文件隔离测试进程，同一文件的测试顺序运行，不并发修改这些变量。

涉及生成的测试注入固定响应、受控等待和合成失败。`https://test.example/v1` 只是配置校验占位，测试不调用该地址或任何外部模型。HTTP 测试只监听临时的 `127.0.0.1` 端口，使用测试 JWT 密钥签发合成账户令牌。

## 本组不覆盖的事项

本组不验证真实模型配置与推理质量，不验证 PostgreSQL 并发行为，不验证 Web 页面或 Android 真机交互，也不证明跨设备网络环境下的体验。409 `CONTEXT_CHANGED` 的结论来自服务端集成测试；本轮没有将浏览器中的 409 提示、刷新预览及重发流程列为已实测。免登录试用的实际 UI 覆盖另见 [TRIAL_WEB.md](./TRIAL_WEB.md)，不能用它代替登录账户的草稿保护、账户切换或跨端验收。用户已确认在真实密钥未提供的条件下按未实测边界交付，本说明不将真实模型验证列为等待事项。

## 只读审查记录

审查范围限于 `src/ai/context.ts`、`service.ts`、`routes.ts` 和 `retrieval.ts`。

- 归属检查：三个资源查询均受用户 ID 限定，课程额外排除归档；知识点查询同时限定所选课程及该课程的用户。预览不调用模型，HTTP 接口经过鉴权且禁止缓存。
- 指纹与快照：指纹包含资源引用、显示标题、准确摘录、来源版本和警告；显式上下文在创建 turn 时保存来源，执行沿用同一快照。失败、取消和过期状态更新均不清除已保存来源；保存回答笔记使用 turn 中的快照。
- 幂等修复：原实现将结构化 context 的 JSON 直接附在普通 message 后散列，导致“附 context 的短消息”与“无 context、正文恰含相同 JSON 后缀的消息”身份相同。现已对附 context 的请求采用带专用前缀的结构化序列化，同时保留无 context 的旧格式。散列冲突及同字段不同顺序合法重试的回归均已通过最终测试。
- 会话历史：显式上下文只替代本次的全局检索，不清空同一会话中最近的成功对话。该行为符合当前契约，因此不能将显式上下文描述成完全隔绝历史回答。
- 长文本：新预览按 UTF-16 长度截取正文，并避免截断表情符号的高代理字符；课程知识点按更新时间与 ID 稳定排序。
- 普通检索修复：新增来源版本和截断标记，并在调用模型前持久化检索快照。第 9 组回归已验证普通关键词检索后的生成失败保留来源；该结果不等于真实向量服务或全部网络失败组合均已实测。
