# 3.2.4 完整游客模式：实现与交付记录

日期：2026-10-30。版本：3.2.4-preview；Android versionCode：14。

用户要求：网页和 Android 均可不注册直接使用当前应用完整功能，使用中的内容跨模块保留，下一次打开不恢复原游客数据。本次为有限补丁；每小时任务和计划保持取消，不恢复自动化。用户随后明确授权新建 `Hyhyhyyy/KeLing4.0` 并发布当前源码及预览包，原上游仓库保持不变。

## 1. 功能边界

“完整游客”复用两端正式主界面和已经实现的模块，不把游客限制在五模块示例页。日常学习功能不要求账号；真实 AI 仍需要有效的个人 Key 或管理员明确开放的公共试用模型。它不代表原应用未完成的功能已自动实现，也不代表真实模型、真机、竞赛要求已全部验收。

| 端 | 入口与运行方式 | 本次数据保留与结束条件 |
| --- | --- | --- |
| Web | `/trial` 启动游客，复用正式主布局、导航和课程／图谱／任务／笔记／AI／编排／报告／个人设置等页面；学习 API 接入内存适配层。 | 站内切换模块保留；刷新、关闭、退出或清空重开结束；前进／后退缓存恢复不沿用旧游客空间。 |
| Kotlin Android | 登录页游客按钮进入 `FullGuestScreen`，复用 `MainAppContent`；正式云工作区、AI、编排、设置及既有本机功能入口在独立游客容器中运行。 | 退出、Activity 销毁重建（包括旋转重建）或进程结束清空；仅后台切换且未被销毁时仍保留。 |

游客数据不参与账号持久化或跨端同步，不自动转存到登录账号。用户主动导出的文件和系统剪贴板副本不属于应用自动清除范围。

## 2. Web 调用链

- `apps/web/src/App.tsx`：游客启动、正式路由放行、全局游客提示与退出；首页、登录、注册提供明显入口。
- `apps/web/src/services/guestSession.ts`：仅当前文档的游客身份、退出通知。
- `apps/web/src/services/guestData.ts`：内存资料与奖励状态；课程、知识点、任务、笔记 CRUD，笔记版本、签到和完成幂等，统计／成就读取。
- `apps/web/src/services/api.ts`、`store/useAppStore.ts`：路由到本次内存工作区，保留正常账号通路；游客未知请求不回退到带 token 的账号网络请求。
- `apps/web/src/services/guestAI.ts`：内存会话、引用版本、取消和迟到响应隔离、回答保存幂等、计划预览与确认。
- `ModelAccessPanel.tsx`、`StellarAssistant.tsx`、`Agent.tsx`：Key 只在当前游客内存跨模块共用，明确展示本次保存与发送范围。

同一计划确认前重新核对资料，失败回滚只作用于原游客空间。准备发送时的并发请求、删除／取消及身份切换均须阻止旧内容进入新空间。

## 3. Android 调用链与生命周期

Android 使用 `FullGuestScreen` → `MainAppContent`，由 `GuestWorkspace.kt` 内存实现 `WorkspaceApi`、`AssistantApi` 和 `AgentApi`。既有本机模块的 `AppViewModel` 注入 `MemoryPreferences`，只实现偏好数据接口，不创建游客磁盘文件、Room 数据库或账号存储。

游客容器使用独立 `ViewModelStore`，不使用可恢复保存状态记录游客内容。游客结束时清理状态与异步请求；`ModelAccessSession` 的 Key 在本次跨模块保留并随游客关闭。界面销毁或进程结束会丢失本次工作，后台切换本身不等于结束。窗口使用 `FLAG_SECURE` 限制系统截图和最近任务预览。

以上是实现及代码审查所说明的生命周期；最终 52 项测试、构建和 lint 结果记录在第 5 节，不能以实现说明代替设备验收。主工作区和临时田园空间保持原应用的两套入口，不自动双向合并资料。

## 4. AI 服务边界

新服务 `apps/server/src/ai/guest.ts` 挂载到 `/api/trial/workspace`，提供 `catalog`、`chat`、`plan`；不创建游客账号，不写学习数据库。

`chat` 使用现有厂商凭据校验和模型传输，支持指定资料、最近会话历史、关键词及同厂商向量检索。`plan` 复用 `validatePlan` 校验来源、日期及每日时长，返回草案，由客户端确认后写本次任务。模型 Key 不进入会话记录；请求结束清除请求对象中的凭据及学习内容。用户 Key 不能选择任意转发地址，未公开的部署模型权限不会自动开放给游客。

无有效 Key，真实模型连通、目录授权、回答质量、向量效果及费用均未实测；当前测试中的模型返回为合成数据。公共试用仅在管理员明确开启指定模型时可用。游客规划调用路径不等于已验证 Huawei AgentArts 运行。
